# 客户视角电话对练：游戏设计审查与优化

Status: ready-for-human

Implementation: complete（2026-10-02，修复与验收见 report.md）

## 目标与边界

让玩家在布置、对局、结算中始终知道自己的角色、下一步操作和重玩价值。保留玩家扮演客户、AI 自动使用全部已发布策略、隐藏信息隔离、不评分、真实素材人工发布等既有边界；保留仓库现有未提交的酒馆牌架与视觉改动。

## 本轮发现与验收

1. 开局缺乏角色和体验目标说明，入座只显示画像标题。补充简短玩法说明与可见/隐藏画像预览。
2. 快捷回复可能虚构客户资金去向、误判已认识的关系，且金额关键词误触产品阶段。改为不预设资金事实的回应，关系以画像为准。
3. 12 格容易被理解为必须打满，缺少剩余轮次与结束状态反馈。明确上限、可提前结束和临近结束提示。
4. 明牌把动作链首项写成实际本轮动作，事后归因未强调候选；已有回复无匹配时仍提示等待亮牌。分别展示匹配依据候选、卡内动作参考与未确认状态。
5. 复盘缺少阅读起点，长来源抢占主线。加事实统计和优先核对轮次，来源可展开，支持同一客户重开并保留原局。
6. 加载失败无法原地重试，加载期可点击快捷回复；中文输入法 Enter 可能误发；零回合不能结束；结束成功而结果失败后前端仍显示可发言。补足并测试这些中断点。
7. 窄屏先堆完整画像再展示聊天，导航与卡面易挤占主操作。验证 1440/900/390 宽度并调整必要的布局。

## 停止标准

两轮审查：主流程体验与证据语义 → 回归与边界复查。所有已确认且在本次权限/产品范围内的问题修复并通过测试、类型与构建、浏览器检查后收口。不能以静态审查证明“永远没有问题”；真实玩家体验和真实模型质量单独记录待验证项。
