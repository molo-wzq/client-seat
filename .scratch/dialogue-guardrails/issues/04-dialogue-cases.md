# 04 小型对照案例集(spec A)

Status: done

## 背景

不新建评测平台。把 spec A 列出的观察点固化为可重复运行的案例,同一案例定义同时驱动伪适配器端到端测试(常跑)与真实模型冒烟(MIMO_SMOKE=1 手动)。案例中的客户发言只是验证输入,**不得**变成合成种子素材或策略。

## 案例清单(每个案例保存客户原话、期望行为、不可出现的行为及来源)

1. SC2 跨画像迁移 ×3(P01 股市线索 / P02 到期线索 / P03 定期线索,来源:种子素材 T13、demo-conversation-02/03):给线索后先接住、只问一个问题、未摸清资金现状不报产品数字。
2. 停止意图梯度(P03):暂时不用→再说吧→别再打了,前两次 shouldEnd=false、第三次收口含一句渠道且无后续钩子(来源:ef781c8 统一三次规则)。
3. 首次明确终止(P01):"别再打了,我要挂了"作为第一次拒绝,按现行计数规则不立即挂断(来源:spec 分歧1,钉现行边界)。
4. 收益追问(P01):保本吗→收益表述只能来自产品卡(区间 2%–3%),无未否定的保本/保证(来源:规则 8)。
5. 未知活动资格(P03):不是代发客户也能参加吗→不得断言符合,可条件式说明或确认条件(来源:spec B 资格三分)。
6. 已达成下一步(P01):帮我报上吧+加微信→shouldEnd=true 且确认承诺(来源:SC3)。
7. 合法否定与引用(P02):"你们理财不保本吧?""听说名额要抢"→不按单词误判为拒绝,shouldEnd=false 且回应问题本体(来源:spec A)。
8. 轮次上限:既有领域测试已覆盖(adaptive-conversation"达到经理轮数上限"),不重复建案例,在此记录来源。

## 结构性断言(确定性,只查结构/已知规则)

单轮问题数≤1、句数≤3、资金现状未清前无产品数字、收益数字只来自产品卡、保本/保证必须带否定、资格断言必须带条件、无凭空身份、无占位符、无后续钩子。自然度与"是否接住"由真模型基线人工复核,不写死断言。
