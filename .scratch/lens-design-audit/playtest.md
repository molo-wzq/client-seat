# 真人试玩判据

本表针对 Playtesting、Flow、Skill、Interest Curve 透镜。尚未邀请或代替真人完成,自动测试与设计者自玩不能填作真人结果。

## 建议一轮样本

先找 3 位首次接触产品的人和 3 位熟悉电话业务的人,每人约 15 分钟。不给操作答案、不要求配合成交。记录行为与原话,不采集真实客户身份或资金信息。

1. 开局前只问“你认为自己扮演谁,这局想弄明白什么？”观察能否找到画像和观察点。
2. 第一局按任意一个预设画像回应,包含一个追问或顾虑,自然决定何时结束。
3. 结算后请其指出一条客户信号和经理的实际关键动作,并展开来源或产品参数核对。记录错误理解,不能只问是否喜欢。
4. 让其自行决定是否重玩。选择重玩的玩家比较两局原文,说出自己的发现与无法确认的地方。不能提示“第二局更好”。
5. 给一条不同场景的真实、已脱敏素材片段,让其解释动作适用条件。此环节检验迁移,不转成产品内考试或给客户打分。

## 优先修复触发条件

| 观察 | 处理 |
| --- | --- |
| 两位以上误认自己是经理、要选卡或必须成交 | 调整首次引导和客户席说明,再次试玩 |
| 找不到观察点或将观察点理解为要服从的任务 | 调整名称、入口与问句 |
| 把用卡匹配或关键词定位当作已确认优秀 | 加强原文核对位置与候选/未确认说明 |
| 把两局差异当作单变量因果或更高分 | 调整并列标签和差异限制说明 |
| 不能自然找到结束、重试或参数核对 | 调整操作优先级,用触屏与键盘复测 |
| 会操作却说不出一个原文支持的发现 | 重审观察问题和结算证据,不能用新增奖励掩盖学习反馈缺口 |
| 无人自发重试、内容被认为重复 | 再审素材覆盖、画像顾虑与兴趣曲线;不能直接断言增加回合就更有趣 |
