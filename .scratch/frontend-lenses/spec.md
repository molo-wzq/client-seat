# 界面透镜复审与前端优化

Status: ready-for-human

范围：布置、对局、复盘、导航与通话记录。保留木质/绿毡/纸牌的游戏个性,不改模型规则、真实素材或客户评分边界。

依据：此前研究的 Flow、Goals、Control、Feedback、Character;本轮核对官方公开 Deck app 的 Physical Interface、Virtual Interface、Transparency、Beauty。入口为 https://deck.artofgamedesign.com/ ,补充卡面分别 /#/card/60、61、62、71。采用本项目的应用推论,不宣称透镜认证。

## 验收

- 布置主顺序为选客户、读画像、选观察点、接通;只读策略和通话逻辑可按需展开,不能挡住主操作。观察点标题不遮挡。
- 手机首屏缩短导航和说明,触屏与键盘均能到达完整导航;当前页面有可感知标记。点击入座后能看到选中的画像与下一步。
- 对局切到资料页面后草稿与正在进行的回复保留;后台通话结束不抢走正在浏览的页面;新对局仍隔离旧回复。
- 复盘先给核对起点和再试入口,长轮次与完整对话按需读;跳转能展开并定位正确原话;不以“已复盘”盖章暗示玩家已理解。
- 历史局可用客户、时间、轮次和观察点区分,可搜索/筛选与逐步加载;不因大量旧进行中记录挡住新局。
- 按钮/折叠入口具有明确焦点,主要触屏控件至少44px;长中文、320/390/820/1024/1440px布局不横向溢出。减少动态效果偏好继续生效。
- 用操作回归验证状态风险,用实机截图/测量验证布局与可读性。当前检查范围的可复现问题修复后再次逐项复审;真实玩家体验仍需真人样本。
