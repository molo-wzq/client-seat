## 修复

- 审批、驳回和批注读取账本的最新工单状态，移除 DemoWorker 私有等待列表。显式无效 ID 不回退其他待办；决定和批注串行执行，重复/并发决定只处理一次。

- Watchdog 在新 progress 到来后保留已经重试的标记，避免反复重试而永不受阻。
