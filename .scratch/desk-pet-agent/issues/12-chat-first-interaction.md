# 12 · 点击优先对话 + 互动感

Status: done
Blocked by: 11

用户 2026-11-05：要加强桌宠的互动感，并且方便对话，**点击后优先进入对话**。

## 对话
- 单击头像：在桌宠旁展开对话面板（卡纸底、黄铜描边，沿用 token），输入框自动获得焦点。快捷环收进面板顶部，变成一排快捷芯片；Ctrl+K 打开同一个面板。
- Enter 发送，Shift+Enter 换行，Esc 关闭。保留历史，本地存最近 50 条，可清空。
- 回复期间显示「…」打字指示，桌宠表情切到 think；delta 到达时逐字显示；结束后按回复里的表情标签切换表情。
- 回复里带快捷动作建议时，渲染成按钮，点了才执行。
- 通话中输入框锁住，提示「通话中，挂断后再聊」，表情反应照常。
- 面板关闭时收到新回复：头像上显示小红点，同时弹出不超过 40 字的气泡。

## 互动感
- 悬停：轻微探头或挥手。
- 戳一下（双击，或快速连点 3 次）：从一组固定台词里轮换回一句，并切换表情，不调模型。
- 拖动中表情变 pout（被拎起来），松手后恢复。
- 闲置超过 3 分钟变 sleepy，再点一下醒来（只是表情变化，不推送消息，也不提示用户）。
- 事件反应：翻开隐藏牌→cheer；举牌→think；挂断→wave；收到待审→头顶出现角标并晃一下。
- 所有动效都遵循 prefers-reduced-motion。

## 测试缝
DeskPet / ChatPanel 的渲染与交互（单击即对话、焦点、快捷键、流式拼接、锁定、红点）；戳一下的台词轮换（纯函数）；事件→表情映射（纯函数）。
