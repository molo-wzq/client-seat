# 素材质量检查表

Status: 草案,待真实素材验证(L1-05)

在拆解前判断一段素材能否进入 L1,以及哪些片段够格被称为"优秀"。核心原则:**通话结果成功不等于每个动作优秀——按动作判定,不按结果默认。** 术语以根目录 `CONTEXT.md` 为准。

## A. 准入检查(整段素材,全部满足才进入拆解)

| 编号 | 检查项 | 判定 |
| --- | --- | --- |
| A1 | 脱敏完成:无姓名、手机号、卡号、身份证号,真实产品名已替换 | 是/否 |
| A2 | 说话人可区分:理财经理与客户轮次完整可辨 | 是/否 |
| A3 | 场景符合:存量生客首次触达(客户是银行已有客户,但与本经理从未接触或关系较弱) | 是/否 |
| A4 | 语言完整:中文为主,关键轮次可听清/可读通 | 是/否 |
| A5 | 结局完整:通话有明确结束(达成下一步、明确拒绝或自然收口),不是半截录音 | 是/否 |

任一项为"否"→ 素材不进入拆解,记录原因;可修复项(如脱敏、说话人标注)修复后重查。

## B. "优秀"判定(对拟标记的动作逐项核对)

对每个拟标记为"优秀"的关键动作,确认:

| 编号 | 检查项 | 判定 |
| --- | --- | --- |
| B1 | 信号响应:动作是对客户当轮信号的回应,不是无视客户的既定脚本 | 是/否 |
| B2 | 目的明确:能说出该动作想取得的单一结果,且服务于阶段目的 | 是/否 |
| B3 | 决策可解释:能向他人解释"为什么在这里这样说"——推进逻辑成立,而非个人话感 | 是/否 |
| B4 | 低压表达:没有施压、纠缠、隐瞒或误导;客户保留说"不"的空间 | 是/否 |
| B5 | 结果支持:该动作之后对话朝阶段目的推进(防御降低、信息增加或意愿改善);单动作效果不可见时,以阶段整体推进为准 | 是/否 |

判定规则:

- B1–B5 全满足 → 可标记"优秀",可提炼策略卡。
- B1–B4 满足、仅 B5 不满足 → 可保留分析,但不作为"优秀"证据,不提炼策略卡。
- B1–B4 任一不满足 → 不得标记优秀;**通话结果再好也不算**。

## C. 片段处置

| 情形 | 处置 |
| --- | --- |
| 整段通过、局部动作不合格 | 整段进入拆解,剔除不合格片段,在案例分析的对应阶段注明轮次与原因 |
| 结果失败但过程含优秀动作 | 素材可用——优秀看过程不看结果 |
| 全段无任何优秀动作 | 不进入 L1,记录原因 |

```markdown
- 剔除片段:〔轮次 + 原因〕
- 结论:〔进入拆解 / 修复后重查 / 不进入 L1〕
```
