# 迁移改写示例(L1-06)

Status: 初步验证(基于单一案例,待更多素材补充)

## 目的

验证策略卡表达的是**动作逻辑**而非原录音的具体措辞:保留动作链,更换客户背景与全部措辞,策略应仍然成立、仍然可执行。

## 改写对象

- 原卡:[cases/C01-SC2-只问现状贴着回答找资金切入点.md](cases/C01-SC2-只问现状贴着回答找资金切入点.md)
- 原背景:代发客户,资金在某证券炒股,闲置资金做国债逆回购
- 改写背景:代发客户,不用证券,闲钱一直放某互联网平台货币基金;经理想引导其关注行内同收益区间但可面对面服务的灵活产品与代发权益
- 改写原则:动作链 6 步**原序原数保留**;措辞全部重写;产品、权益、恭维内容随背景更换

## 改写后的卡

# 策略卡 SC-C01-2T:只问现状,贴着回答找资金切入点(货基客户变体)

- 状态:草稿(改写验证用,不是从独立素材提炼)
- 改写自:SC-C01-2 / 来源案例 C01

## 触发信号

- SC1 完成后客户愿意继续听;
- 客户对"平时钱怎么打理"给出实质回答;
- 客户说出任何资金去处(货基、零钱理财、定期到期等)。

## 适用场景

存量生客首次触达的中段;客户资金以现金管理类为主(货基/零钱理财),对收益差距不敏感,但对服务和权益可能有感。

## 当前目的

摸清客户资金去处和打理习惯,找到客户自己说出的"不方便点或低效点",为下一步引发兴趣备料。

## 动作链

1. 开放式现状提问,一次只问一个("平时工资之外的钱,您一般都放哪里?")——只问现状,不提产品。
2. 接住每个回答并恭维具体化("您这个安排挺稳健的,平时都不用操心")——让客户愿意展开。
3. 贴着回答往下钻一层("那大额一点的,您也直接放里面吗?")——逼近"图方便还是图收益"的真实考量。
4. 让客户自己说出习惯与理由——切入点必须来自客户口中。
5. 先认可再对比("图方便没问题……不过同样灵活的选择里,其实有收益相当但服务更近的")——不否定现状,只摆出替代项;紧接把代发客户权益说具体。
6. 引用客户自身情况制造相关性("您是代发客户,这类权益本来就是给您留的")——把话题落回"您的情况"。

## 表达原则

- 现状阶段不出现任何产品名和收益数字;
- 恭维具体、贴合客户的实际选择;
- 对比用"同样灵活的选择里"这类相对表述,不贬低客户在用的平台;
- 权益内容一次说清,能量化就量化;
- 单轮不超过三句。

## 参考话术

- 骨架:"平时您工资之外的钱,一般都放哪里打理?也是直接放〔客户说出的去处〕吗?"
- 骨架:"您是代发客户,像〔某权益〕这种本来就是给您这个群体留的,放到您身上正好合适。"

## 适用条件

- 客户愿意连续回答现状问题;
- 经理了解该客群常见的资金去处,能接得住回答;
- 手里有与"现金管理+权益"对接的产品或活动。

## 停止条件

- 客户连续两轮只给单字回应 → 停止追问,直接给出本次来电具体事由,或礼貌收口;
- 客户反问来意 → 如实说明,视回应决定继续或收口;
- 客户明确说"不需要" → 停止本卡,转体面收口,不做二次尝试。

## 验证记录

| 检查项 | 结论 |
| --- | --- |
| 动作链是否原序原数保留 | 是(6 步对应 6 步,仅对象由"证券收益差"换为"便利偏好与权益归属") |
| 措辞是否全部重写 | 是(无一句沿用原录音措辞) |
| 触发信号/停止条件结构是否保持 | 是 |
| 改写后卡是否仍可独立执行 | 是——读改写卡的人不需要知道原录音即可照做 |

## 初步结论

同一动作链在更换客户背景与措辞后仍然完整可执行,支持"策略卡沉淀的是可迁移打法而非话术原文"的判断。**限制**:本验证基于单一案例、由拆解者自己改写,存在自我印证风险;待软拒绝、明确拒绝类素材拆解后,用"跨案例套用"(把 A 案例的策略卡套到 B 案例的背景上)做更严格的复核。

# 跨案例套用复核(ADR 0003 决定 6,2026-09-08)

## 改写对象

- 原卡:[cases/C01-SC2-只问现状贴着回答找资金切入点.md](cases/C01-SC2-只问现状贴着回答找资金切入点.md)
- 原背景(C01/素材01):存量代发客户首次触达,资金在证券炒股,闲置做国债逆回购,经理手上有 T+1 产品与拉新活动
- **目标背景(C03/素材03)**:存量客户,三年定期本周六到期(自动转活期),续存方向已确认;他行另有一笔资金约 1 月中旬到期;经理手上有开门红活动(新资金分档立减金)与贵宾客户路径(50 万门槛)
- 改写原则:动作链 6 步**原序原数保留**;措辞全部重写;对象由「证券/逆回购的机会成本」换为「他行资金的效率与身份权益」

## 改写后的卡

# 策略卡 SC-C01-2T2:只问现状,贴着回答找资金切入点(到期续存客户变体)

- 状态:草稿(跨案例改写验证用,不是从独立素材提炼)
- 改写自:SC-C01-2 / 来源案例 C01,目标背景 C03(素材03)

## 触发信号

- 到期续存确认后,客户资金话题仍在继续;
- 客户对"其他资金怎么放"给出实质回答;
- 客户透露出任何他行资金/待配置资金线索(到期、闲置、活期)。

## 适用场景

存量客户维护的续存沟通中段:到期资金去向已定(续存/转存),但客户完整资产图景未知;经理手里有分档权益活动与身份权益(贵宾),需要找到"客户自己说出的"可对比点。

## 当前目的

摸清客户除到期资金外的资金安排(他行资金、闲置活期),找到客户自己说出的可引导点,为活动与贵宾路径备料。

## 动作链

1. 开放式现状提问,一次只问一个("除了这笔到期的,您其他资金一般是放在哪些地方?")——只问现状,不提产品。
2. 接住每个回答并恭维具体化("您这样分开放也挺稳当,各管各的")——让话少的客户愿意多说一句。
3. 贴着回答往下钻一层("那那笔到期的,到时间您打算怎么安排?放活期还是再看?"——逼近"有没有他行/闲置资金"的真实图景)。
4. 让客户自己说出安排与原因——切入点必须来自客户口中。
5. 先认可再对比("都放定期也稳当……不过他行那笔钱到期时,赶上我们开门红档位的话,立减金和贵宾权益倒是能一起拿")——不否定现状,只摆出可叠加的权益;紧接把档位说具体。
6. 引用客户自身情况制造相关性("您本来就有三年定期在这边,再凑上他行那笔,总资产就够贵宾线了")——把话题落回"您的账"。

## 表达原则

- 现状阶段不出现新产品的收益数字(续存利率已在前面报过);
- 恭维贴合客户的具体安排;
- 对比用"都能拿到/一起拿"的叠加表述,不贬低客户他行的选择;
- 档位金额一次说清;
- 单轮不超过三句。

## 参考话术

- 骨架:"除了这笔到期定期,您平时其他闲钱一般都放哪?也是定期还是活期?"
- 骨架:"他行那笔一月中旬到期——正好,开门红档位您要够得着的话,立减金跟贵宾权益可以一起拿,不冲突。"

## 适用条件

- 客户已确认续存/转存方向(本卡是深化,不是起手卡);
- 客户愿意回答资金现状问题;
- 经理对客户资产有基本了解,接得住"他行、定期、活期"任一路回答。

## 停止条件

- 客户连续两轮单字回应且无新增信息→停止追问,回到已确认的续存安排收口;
- 客户明确表示他行资金不打算动→认可,退回服务关系收口(见 C02-SC3 形态);
- 客户反感资产追问→道歉收口,只保留到期提醒。

## 验证记录

| 检查项 | 结论 |
| --- | --- |
| 动作链是否原序原数保留 | 是(6 步对应 6 步,仅对象由"证券机会成本"换为"他行资金与权益叠加") |
| 措辞是否全部重写 | 是(无一句沿用原录音措辞) |
| 触发信号/停止条件结构是否保持 | 是(触发的"资金线索"类型随背景收窄到他行/待配置资金) |
| 改写后卡是否可独立执行 | 是——读卡人不需要知道 C01 原录音即可照做 |
| 与目标案例 C03 人工卡的关系 | 与 C03-SC3(线索联动升级路径)同属"利用客户资产线索",但本卡是前置的"探图景"步骤,人工版 C03 缺少此步——改写过程反哺出 C03 卡集的缺口提示 |

## 跨案例复核结论

C01-SC2 的动作链完整迁移到到期续存客户背景后仍可独立执行;动作对象随背景更换而收紧(证券→他行资金),但 6 步决策结构(问现状→接住→下钻→等客户说出→认可对比→落回自身)未变形。**支持"策略卡沉淀的是动作逻辑而非话术"的判断,且从单案例自我改写升级为跨案例套用。** 局限:改写由同一代理完成,套用结论未经第二人独立执行验证(与独立重拆复核同批局限,见 `review/复核记录-独立重拆.md`)。
