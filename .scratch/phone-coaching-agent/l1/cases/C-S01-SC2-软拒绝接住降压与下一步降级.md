# 策略卡 SC-C-S01-2:软拒绝接住降压与下一步降级

- 状态:草稿(合成素材提炼,仅供验证;不入产品种子)
- 来源案例:[C-S01-案例分析.md](C-S01-案例分析.md)(阶段 3–4)
- 来源片段:素材04 T06–T12

## 触发信号

- 客户表达软拒绝:再说吧/钱有安排/暂时不考虑/到时候再看;
- 或连续两轮只给敷衍回应。

## 适用场景

首次触达或维护触达中,客户不关门但也不接话。目标从「达成承诺」降级为「保留渠道」。

## 当前目的

接住拒绝、解除压力,把下一步降到客户零成本可接受的程度。

## 动作链

1. 认可客户的安排(「钱都有安排那是好事」)——拒绝先接住,不辩解。
2. 把稀缺讲成常态(「这活动每个月都有,什么时候有闲钱都来得及」)——主动消解紧迫感,换客户不设防;不追问客户资金细节。
3. 下一步降级:报名→到访→加微信→发资料,逐级降到客户零成本(「发您一份,有空翻翻就行」)。
4. 明确去除互动负担(「不用回复我」)——零义务的许可才拿得到。
5. 经理先收口(「不多打扰您忙了」),不附加新钩子。

## 表达原则

- 接住只用一句,立刻转向降压,不停在道歉上;
- 「常态」表述只此一次,反复说就变成变相催促;
- 降级动作必须真实可做(微信渠道确认存在,才承诺发资料);
- 客户接受降级动作后立即收口,不再追加任何提议。

## 参考话术

- 原话:「理解理解,您钱都有安排那是好事。那不催您,这活动每个月都有,您什么时候有闲钱了都来得及。」(T07)
- 原话:「我微信上把活动说明发您一份,您有空翻翻就行,不用回复我。」(T09)
- 骨架:「理解,您安排好了那最好。这事不急,〔常态化表述〕。我把〔资料〕发您,您有空看看就行,不用回我。」

## 适用条件

- 拒绝是软性的(推脱、犹豫),客户仍在线且语气平和;
- 客户未明确说「不需要/别打了」(那是明确拒绝,走接住收口路径,见 C-S02);
- 降级后的动作真实可兑现。

## 停止条件

- 同一通话内软拒绝出现第二次→跳过一切提议,直接进入降级下一步;
- 软拒绝转为明确拒绝→立即转接住收口(见 SC-C-S02-1);
- 客户挂断倾向明显→致谢收口,降级动作也放弃。
