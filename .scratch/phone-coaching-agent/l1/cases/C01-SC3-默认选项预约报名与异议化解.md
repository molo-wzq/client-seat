# 策略卡 SC-C01-3:默认选项预约报名,异议即解释,落到加微信

- 状态:草稿
- 来源案例:[C01-案例分析.md](C01-案例分析.md)(阶段 4)
- 来源片段:素材01 T15–T26
- 提炼人 / 日期:ZCode(代理办) / 2026-09-08

## 触发信号

- 客户对产品/活动给出正面或中性回应("好的""可以""了解了");
- 客户表达犹豫但未拒绝("但是我那个钱要月底才到");
- 客户在做决定前核实自己的自由度("那我不存进来也可以对不对?")。

## 适用场景

存量生客首触的收尾段:兴趣已建立,需要一个可兑现的下一步;下一步可以是报名、预约面谈、领取权益或加微信——关键是低成本、可取消。

## 当前目的

把兴趣落成具体承诺(报名/预约/加微信),并让客户确认"随时可以反悔",不产生被强制的感受。

## 动作链

1. 默认选项式预约("要不要先给您预约报名一下?")——把决策从"要不要参加"简化为"要不要我帮您办",办了也可以取消。
2. 客户犹豫时先解释规则,不绕开疑虑("31 号之前资金不用转进来都可以参加")——犹豫背后常是误解,解释掉误解比重复好处有效。
3. 客户核实自由度时痛快放行("哎对,不用的话不转进来也可以,下个月参加也行")——放行本身就是促成,高压话术在这里通常反而模糊回应。
4. 给出建议档位而不是让客户空选("先给您报名 20 万这一档")——客户只需同意或调整,不用自己做算术。
5. 落到一个更轻的下一步(加微信)——即使主承诺后续生变,联系渠道已经建立。
6. 预告后续服务并先说"不打扰"收口("以后有专属权益我提前通知您……那先不打扰您")——把一次性推销转为长期关系,由经理主动结束通话。

## 表达原则

- 预约用"要不要我帮您……"句式,不用"您要不要参加";
- 客户任何疑虑先解释再推进,一次说不清就收窄请求(从报名降为加微信);
- 放行自由度时语气干脆,不附带条件("可以,不过……"会抵消放行效果);
- 紧迫感信息(活动截止、额度稀缺)最多出现一次,陈述事实即可,不施压;
- 收口必须由经理先说"不打扰",不等客户找理由挂断。

## 参考话术

- 原话:"您看我这边要不要先给您预约报名一下20万的那一档?你看可以吗?"(T18)
- 骨架:"那我看要不要先帮您把〔这一档/名额〕报上?到时候您方便再确认就行。"
- 原话:"嗯,没关系的。就是只要那个31号之前呢您的这个资金不用呢转进来都是可以参加的。"(T18)
- 骨架:"没关系的,〔客户担心的条件〕其实不影响,只要〔规则〕之前都来得及参加。"
- 原话:"那之后呢像我们这种代发工资的专属的权益啊还有活动呢,我都会那个提前的这个通知您的……那先不打扰您,就这样,拜拜。"(T24、T26)
- 骨架:"之后有〔这类客户〕专属的活动,我都提前微信上告诉您。那先不打扰您了,再见。"

## 适用条件

- 客户已表现出兴趣或至少中性认同,未出现明确拒绝;
- 所承诺的下一步真实可兑现(活动真实存在、规则说得清),不许诺不确定的事;
- 客户尚未接收到活动规则的关键信息(截止时间、参与条件)时,先讲清再预约。

## 停止条件

- 客户明确说"不用了/不需要" → 停止本卡,致谢收口,不二次推销;
- 客户连续两次回避默认选项(不接话、转换话题) → 降级请求为加微信;再回避即收口;
- 客户提出经理无法当场回答的问题 → 如实说"这个我确认后回复您",以此为由落加微信,不现场编造。
