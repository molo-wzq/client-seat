## 1. 场景

- 设定:客户C是某银行代发客户,与本经理无既往接触;行内月底前有代发客户新资金活动(微信立减金分档);经理主动外呼告知。
- 本案例验证的重点不是「谈成」,而是:软拒绝出现后,经理如何在不施压的前提下维持关系与沟通渠道。

## 2. 客户状态(通话开始时)

- 态度:忙、不耐(「正忙着呢,你哪个银行的?」,T02);对电销有戒心。
- 处境线索:资金「都有安排」(T06);不排斥听一句话,但排斥被占用时间。
- 初始意愿:低,但未关门。

## 3. 总体目标

不在当次达成任何承诺;把「无压力的资料渠道」留下,体面结束。

## 4. 对话阶段

### 阶段 1:时间盒开场(T01–T04)

| 字段 | 内容 |
| --- | --- |
| 阶段目的 | 用「就一分钟」化解「忙着呢」,争取最小倾听窗口 |
| 客户信号 | 「正忙着呢」+盘问归属(「你哪个银行的?」);随后「行,你说」——给了窗口 |
| 推进逻辑 | 忙不是拒绝,是时间约束:自报归属→给出明确时长承诺(一分钟)→说明说完即止(「说完您接着忙」)。约束越明确,客户越愿意给这一分钟 |
| 关键动作 | ①自报身份;②给时间盒(一分钟+说完接着忙);③等客户放行(「行,你说」)再讲内容 |
| 代表话术 | 「就一分钟,有个代发客户的活动跟您说一声,说完您接着忙。」(T03)——体现动作② |

### 阶段 2:权益一句话报清(T05)

| 字段 | 内容 |
| --- | --- |
| 阶段目的 | 在窗口内把活动说清:身份依据、档位权益、「不着急」定性 |
| 客户信号 | 沉默听完,未打断 |
| 推进逻辑 | 一轮内完成:身份依据(代发客户)+活动(月底前新资金活动)+权益(五万档五十/二十万档一百五)+去压力定性(「不着急的话到时候看看」)——信息密度高但全部是事实,无形容词 |
| 关键动作 | ①身份依据+活动一句带过;②分档权益报清;③「不着急」定性,把决定权推后 |
| 代表话术 | 「不着急的话,您到时候看看。」(T05)——体现动作③ |

### 阶段 3:软拒绝接住与降压(T06–T08)

| 字段 | 内容 |
| --- | --- |
| 阶段目的 | 客户表达软拒绝后,接住、认可、明确不催 |
| 客户信号 | 「再说吧,我这钱都有安排的,暂时不考虑」(T06);「到时候再看吧」(T08)——连续软拒绝 |
| 推进逻辑 | 接住三步:认可(「钱都有安排那是好事」)→不催(「这活动每个月都有,什么时候有闲钱都来得及」)——把活动的稀缺性主动降为常态化,用「不稀缺」换「不设防」。不追问「那您钱怎么安排的」 |
| 关键动作 | ①认可客户的安排;②活动常态化表述(随时来得及);③不追问资金细节 |
| 代表话术 | 「理解理解,您钱都有安排那是好事。那不催您,这活动每个月都有,您什么时候有闲钱了都来得及。」(T07)——体现动作①② |

### 阶段 4:降级下一步与体面收口(T09–T12)

| 字段 | 内容 |
| --- | --- |
| 阶段目的 | 把承诺降到零压力(发资料、不用回复),由经理主动收口 |
| 客户信号 | 「到时候再看吧」(T08)持续不承诺;T10 勉强接受(「……行吧,你发过来吧」) |
| 推进逻辑 | 正常下一步(报名/到访)明显不可得,降级为「微信发资料,不用回复」——客户付出的成本趋近于零,所以能接受;接受后立即收口,不再附加任何新提议 |
| 关键动作 | ①下一步降级为发资料;②明确「不用回复我」;③经理先说「不多打扰」并收口 |
| 代表话术 | 「我微信上把活动说明发您一份,您有空翻翻就行,不用回复我。」(T09)——体现动作①② |

## 5. 优秀原因

1. **时间盒开场**(T03):对忙客户,「一分钟+说完接着忙」比「耽误您两分钟」可信——因为有明确的终止承诺。对应 C-S01-SC1。
2. **把稀缺讲成常态**(T07):「每个月都有」主动消解紧迫感,换取客户不设防——软拒绝场景里,降压价值高于成交价值。对应 C-S01-SC2。
3. **下一步降级**(T09):报名→到访→加微信→发资料,逐级降档后客户能接受;「不用回复我」把互动成本降到零,反而获得许可。对应 C-S01-SC2。
4. **由经理先收口**(T11):「不多打扰您忙了」——通话的结束权始终在经理手里,客户不必找理由。

做得一般、不值得复用的动作:

- T09 的发资料动作在真实业务中须确认客户微信可触达;合成素材默认可触达,复用时注意先有渠道再承诺。
- T02 客户盘问「哪个银行的」出现在自报之后,说明 T01 自报身份的音量/清晰度不足;真实通话中自报要说清。
