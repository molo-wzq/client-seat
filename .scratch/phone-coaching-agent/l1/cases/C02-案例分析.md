# 案例 C02:存量客户跟进,把资金节点变成服务接触点

- 素材来源:[../transcripts/02-存量客户跟进-理财衔接.md](../transcripts/02-存量客户跟进-理财衔接.md)
- 素材检查:通过(见 [../transcripts/02-检查记录.md](../transcripts/02-检查记录.md);A3 按追加决议 7 放宽口径)

- 分析日期:2026-09-08
- 素材类型:顺利沟通(存量客户维护·跟进触达)
- 提炼策略卡:C02-SC1、C02-SC2、C02-SC3(同目录)

## 1. 场景

- 已知事实:客户A是某银行存量客户,名下 15 万资金即将到账(利息约四千七百块,约 2.7%);经理此前已与她沟通过到账事宜;行内不定期推出福利,近期有一款福利款理财(利息基准 2.45%–3.15%),可能本月发行;客户周五上午会来网点。
- (推测)经理对本客户的资金节点(到账日)有台账级掌握,外呼前已核过利息,属于有准备的维护型触达,不是盲打。

## 2. 客户状态(通话开始时)

- 态度:信任、放松——称呼亲昵(阿姨),接话顺畅,主动把事情交给经理("帮我在看一下吧,哪个理财好啊",T06)。
- 处境线索:有三年定期(偏好稳健,资金不活跃);"可能也不存的啦,都是三年的"(T14)。
- 初始意愿:对理财有开放兴趣,但无明确承诺。

## 3. 总体目标

锁定周五到访,把到账资金与福利款理财衔接,并建立"到期/福利提前告知"的长期服务节奏——不是当场促成购买。

## 4. 对话阶段

### 阶段 1:征询接话 + 到账预告(T01–T03)

| 字段 | 内容 |
| --- | --- |
| 阶段目的 | 确认接话时机,把「钱要到账」这一节点信息送到,建立本次通话的服务正当性 |
| 客户信号 | 「方便的」(T02)——允许继续;对到账信息无打断 |
| 推进逻辑 | 跟进电话的优势是「有正事」:先报到账时间和利息具体数字(四千七百块、两点七),客户立刻知道这通电话与自己的钱有关,不是推销 |
| 关键动作 | ①征询接话时机;②到账时间预告(明晚);③利息具体化(四千七、2.7%) |
| 代表话术 | 「应该到账的话是明天的晚上这样子,十五万,利息的话还是蛮不错的哦,大概有四千七百来块」(T03)——体现动作③ |

### 阶段 2:确认资金用途,顺势接需求(T04–T07)

| 字段 | 内容 |
| --- | --- |
| 阶段目的 | 让客户自己说出资金安排与需求,经理只接不推 |
| 客户信号 | 「我不用的」(T06);主动提问「哪个理财好啊?」(T06)——需求由客户口中说出 |
| 推进逻辑 | 用封闭确认(「你这钱是不用的,是不是啊?」)让客户陈述安排;客户随即自问理财——经理此时不需要推销,只需要接住 |
| 关键动作 | ①封闭式确认资金用途;②接住客户问题,不抢答(先「嗯,哦,对」) |
| 代表话术 | 「那不用你就帮我在看一下吧,那哪个理财好啊?」(T06,客户语)——需求自发产生 |

### 阶段 3:锁定到访 + 时间点衔接(T08–T11)

| 字段 | 内容 |
| --- | --- |
| 阶段目的 | 把模糊的「来网点」落成具体时间,并把理财推荐挂接到到账时间点上 |
| 客户信号 | 主动报出到访计划「礼拜五」并给出具体时间「十点」(T08–T10) |
| 推进逻辑 | 客户已有到访意愿,经理做三件事:把时间钉死(十点左右)、给客户一个到访前的小动作(回去看到期日,跟我说一声)、把福利+具体理财+时间点串成「刚好凑上」——让来网点变成顺理成章 |
| 关键动作 | ①确认具体到访时间;②布置到访前小动作(核对到期日);③福利预告+具体理财(利率区间)+时间点衔接 |
| 代表话术 | 「近期的话有个理财也还蛮不错的,利息基准大概在两点四五到三点一五左右……有可能就是这个月就发行那么一款,那这样子的话你也刚好凑在这个时间点上」(T11)——体现动作③ |

### 阶段 4:开口活期敞口,不强推收口(T12–T16)

| 字段 | 内容 |
| --- | --- |
| 阶段目的 | 探一下除定期外的资金敞口,无论结果如何都把关系放在成交之前 |
| 客户信号 | 「好的好的」(T13);「我可能也不存的啦,都是三年的」(T14)——温和拒绝新配置 |
| 推进逻辑 | 客户不接活期话题时,经理不纠缠:先认可现状(「是的,是的」),再给一句不设压力的开放建议(「放那里……你理财有一些钱这样也好的」),然后自然收口。跟进电话的成败不在当次成交,在「下次还愿意接」 |
| 关键动作 | ①开放式探资金敞口(一次);②认可现状不纠缠;③开放建议+自然收口 |
| 代表话术 | 「反正这样,放在那里也……你理财有一些钱这样也好的啊」(T15)——体现动作③ |

## 5. 优秀原因

1. **利息具体化**(T03):不说「利息不错」而说「四千七百来块、两点七」——数字让客户立刻感知这通电话的价值。对应 C02-SC1。
2. **让需求从客户口中说出**(T05–T06):经理只做封闭确认,「哪个理财好」由客户主动问出——服务型触达的高音量动作是零推销。对应 C02-SC1。
3. **到访时间钉到点**(T09–T10):「礼拜五」被追到「十点左右」,模糊意愿变成可执行的日程。
4. **给客户到访前的小动作**(T11「回去看一下大概什么时候到期」):客户参与感+下次通话的自然由头。对应 C02-SC2。
5. **福利+理财+时间点三合一衔接**(T11):不孤立推产品,而是「这个月刚好有一款+您刚好这个节点来」——相关性与稀缺感都来自事实。
6. **不强推、留开放口**(T14–T15):客户温和拒绝后,认可现状+一句开放建议收口——跟进关系里「下次还愿意接」比当次成交值钱。对应 C02-SC3。

做得一般、不值得复用的动作:

- T07「嗯,哦,对」接客户的到访信息略显含糊,可以顺势直接确认「礼拜五上午我来给您留着时间」。
- T11 一轮内信息偏多(到期核对+福利+理财+利率),电话里可拆两轮说。
