## 1. 场景

- 设定:客户D是某银行存量客户,与本经理无既往接触;经理主动外呼告知行内活动;客户接通即明确拒绝,并表达对银行来电的反感(「别老打电话了」)。
- 本案例把 ADR 0001 预留的通用「接住—收口」路径正式化:当策略库中没有任何卡的条件被满足时,经理应走的最低保障路径。

## 2. 客户状态(通话开始时)

- 态度:抗拒——明确拒绝(「不需要」)+行为性抱怨(「别老打电话了」)。
- 处境线索:未知,也不必在本通电话中探索。
- 初始意愿:无。

## 3. 总体目标

不推进任何事项;致歉、留一条不打扰的服务渠道、无冲突结束。

## 4. 对话阶段

### 阶段 1:接住与致歉(T01–T04)

| 字段 | 内容 |
| --- | --- |
| 阶段目的 | 让「拒绝」被完整接受,不产生第二次推销的印象 |
| 客户信号 | 「不用不用,我不需要,你们别老打电话了」(T02)——三连:拒绝+去留渠道之外的抱怨;「嗯」(T04)——冷淡但仍在听 |
| 推进逻辑 | 明确拒绝后只有一个正确动作:立即接受(「好的好的」)+致歉(「抱歉打扰您了」)+宣布停止(「那这个事就不提了」)。任何解释、任何「是这样的」都会把 T02 的不满放大 |
| 关键动作 | ①立即接受拒绝,不接第二句;②致歉;③明确宣布不再提此事 |
| 代表话术 | 「哎,好的好的,抱歉打扰您了,那这个事就不提了。」(T03)——体现动作①②③ |

### 阶段 2:留服务渠道与收口(T05–T08)

| 字段 | 内容 |
| --- | --- |
| 阶段目的 | 在不推翻「不再打扰」承诺的前提下,留一条客户主动触达的渠道 |
| 客户信号 | 「嗯」(T04)持续冷淡;「行,知道了」(T06)——中性接受;「拜拜」(T08)——正常告别 |
| 推进逻辑 | T05 的定位是「一次性的服务告知」而非推销:先自我设限(「以后也不经常打扰」),再留渠道(「有资金上的事可以找我」),附一个最低限度的身份记忆点(「我姓某」)。说完立即收口,不验证客户反应 |
| 关键动作 | ①自我设限(以后不常打扰);②留主动触达渠道+身份记忆点;③经理先收口 |
| 代表话术 | 「万一您哪天有资金上的事要咨询,到网点或者打电话都找我,我姓某。」(T05)——体现动作② |

## 5. 优秀原因

1. **拒绝后零挽留**(T03):明确拒绝的当轮没有任何解释或第二次尝试——挽留本身会被记成「纠缠」,接住反而保住下次可能。
2. **自我设限**(T05「以后也不经常打扰」):把客户「别老打电话」的抱怨正面接走,以承诺回应抱怨,而不是辩解「我们不是推销」。
3. **渠道留的是「服务」不是「下次推销」**(T05):「有资金上的事要咨询」是客户主动的场景;对比「那我过阵子再给您介绍」,前者不侵占客户预期。
4. **收口由经理完成**(T07):「那就不打扰您了,您忙,再见」——客户只需要说拜拜。
5. **全程短**:明确拒绝场景里,通话时长是最重要的低压指标——本案例 8 轮结束,超过 10 轮即视为失败。

做得一般、不值得复用的动作:

- T01 报出「行里针对存量客户的活动」作为开场事由,在明确拒绝型客户上注定触发拒绝;对已知反感的客户,开场事由应更中性(资产服务、到期提醒等)。合成素材保留此瑕疵以呈现完整路径。
