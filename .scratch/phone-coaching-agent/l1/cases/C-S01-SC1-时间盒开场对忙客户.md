# 策略卡 SC-C-S01-1:时间盒开场(对忙客户)

- 状态:草稿(合成素材提炼,仅供验证;不入产品种子)
- 来源案例:[C-S01-案例分析.md](C-S01-案例分析.md)(阶段 1–2)
- 来源片段:素材04 T01–T05
- 提炼人 / 日期:ZCode(代理办) / 2026-09-08

## 触发信号

- 客户接通即表示在忙(「正忙着呢」「我在开会」)或语气急促;
- 常规开场无法继续(客户不听第二句)。

## 适用场景

首次触达或维护触达中,客户时间受限。目标不是完成沟通,是拿到一个明确的最小倾听窗口。

## 当前目的

获得客户对「一分钟陈述」的许可。

## 动作链

1. 自报机构归属(「某银行的」)——忙客户第一个问题是「谁」,先答它。
2. 给时间盒(「就一分钟」)——明确的时长承诺,越具体越可信。
3. 给终止承诺(「说完您接着忙」)——把「结束权」提前交给客户。
4. 停止陈述,等客户放行(「行,你说」)——放行后再讲内容;不放行就约改天。

## 表达原则

- 三句话内完成 1–3,不加寒暄;
- 时间盒说一的就是一,超时自己先收;
- 客户未放行前不报任何活动内容。

## 参考话术

- 原话:「就一分钟,有个代发客户的活动跟您说一声,说完您接着忙。」(T03)
- 骨架:「就一分钟,有件〔事由〕跟您说一声,说完您接着忙。」

## 适用条件

- 客户的忙是时间约束而非情绪抗拒(情绪抗拒先接住道歉,不用本卡);
- 陈述内容真能在一分钟内说完(一句话事由+一句话权益);
- 客户未挂断。

## 停止条件

- 客户不给窗口(「没时间」并挂断倾向)→「那您方便的时候我再联系您」,收口;
- 一分钟陈述完毕客户仍无回应→感谢接听,收口。
