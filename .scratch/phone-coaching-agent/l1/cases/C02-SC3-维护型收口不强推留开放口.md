# 策略卡 SC-C02-3:维护型收口——不强推、留开放口

- 状态:草稿
- 来源案例:[C02-案例分析.md](C02-案例分析.md)(阶段 4)
- 来源片段:素材02 T12–T16
- 提炼人 / 日期:ZCode(代理办) / 2026-09-08

## 触发信号

- 客户温和拒绝新配置(「不存的啦,都是三年的」)或对提议不接话;
- 本轮主要目标(到访、续存等)已达成,通话进入收口窗口。

## 适用场景

存量客户维护的收尾:客户整体信任经理,但当下不接受新提议。目标是「下次还愿意接电话」,不是当次成交。

## 当前目的

认可客户现状,留一个不设压力的开放建议,自然收口。

## 动作链

1. 开放式探一次资金敞口(「除了定期,有没有活期或不定时放着的钱?」)——只探一次,客户不接就过。
2. 认可客户现状(「是的,是的」「都是三年的,稳健」)——拒绝不是异议,是客户的安排,先接住。
3. 给一句不设目标的开放建议(「放那里也好,理财有一些钱这样也好的」)——把「理财」重新定义成日常安排而非任务,不追问、不解释、不举例。
4. 自然收口(「好的好的,那我就先这样」)——由发起方先收,不让客户找理由挂断。

## 表达原则

- 探敞口只问一次;客户不接话,绝不开第二口;
- 认可要具体到客户的安排本身(三年期、稳健),不空夸;
- 开放建议一句话封顶,语气像「顺口一提」;
- 收口干脆,不附加「那您考虑一下」「回头我再联系您」之类的新钩子(后续跟进由服务节奏自然产生)。

## 参考话术

- 原话:「反正这样,放在那里也……你理财有一些钱这样也好的啊。」(T15)
- 骨架:「都放定期也稳当。就是留着些灵活的钱,有合适的(机会)也方便,您看着安排。」

## 适用条件

- 客户与本经理有信任基础(维护型关系);
- 客户的拒绝是温和的安排性拒绝,不是情绪化抗拒(后者先接住道歉,见拒绝类策略);
- 本轮服务目标已完成或已确认无法推进。

## 停止条件

- 本卡本身就是收口动作:说完开放建议即收口,客户若接话则顺势回应,不再发起新提议;
- 客户情绪转差→致歉并立即结束,开放建议也省略。
