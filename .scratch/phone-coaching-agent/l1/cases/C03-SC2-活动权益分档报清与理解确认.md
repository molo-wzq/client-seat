# 策略卡 SC-C03-2:活动权益分档报清与理解确认

- 状态:草稿
- 来源案例:[C03-案例分析.md](C03-案例分析.md)(阶段 2)
- 来源片段:素材03 T06–T10
- 提炼人 / 日期:ZCode(代理办) / 2026-09-08

## 触发信号

- 客户接受续存或资金话题后,引入活动/权益的最佳窗口;
- 或客户对活动规则表现出不确定(反问「新存进来是不是啊?」)。

## 适用场景

存量客户触达中段:行内有分档权益类活动(立减金、礼品),需要客户准确理解「怎样能拿到、拿到多少」。

## 当前目的

让客户准确理解活动规则,消除「是不是有附加条件」的疑虑。

## 动作链

1. 场景化引入(「现在是开门红活动」)——给活动一个时间正当性,不突兀。
2. 分档权益一次报清(「五万以上五十的立减金,二十万一百五,五十万三百」)——档位+对应奖励成对说出。
3. 补充非资金类权益(线下礼品)与适用范围。
4. 主动核对客户理解(「最近有他行到期吗?」以场景带出规则)或回应客户反问;
5. 疑问即时解释,解释完回到权益本身(「理财、买定期都可以的」——消除「只能存特定产品」的误解)。

## 表达原则

- 档位金额成对报,顺序从低到高,中间不插话;
- 客户任何反问先直接回答(对/可以/都行),再补充范围;
- 不用「最高可享」「还有更多惊喜」这类模糊话,规则是什么就是什么;
- 客户被动时可完整复述一遍关键规则——信息重复、语气不加重。

## 参考话术

- 原话:「有新资金存入五万以上,到时候会有一个五十的立减金,然后还会有线下的礼品送的。」(T06)
- 原话:「对对对,新存进来啊,你做理财、买定期都可以的。」(T08)
- 骨架:「新资金〔档位〕以上有〔具体奖励〕,〔高一档〕是〔奖励〕,按档叠加上去的。」

## 适用条件

- 活动规则、档位、奖励真实且说得准;
- 客户已进入资金话题(未了解需求前不报权益金额,见对话硬性规则);
- 客户未明确拒绝当前话题。

## 停止条件

- 客户对活动无任何回应且连续单字→跳过细节,只留一句「回头我把活动说明发您」;
- 客户明确说不需要活动→致谢收口,不报档位;
- 客户问到答不上的规则细节→如实说「这个我确认后回复您」,以此落回访。
