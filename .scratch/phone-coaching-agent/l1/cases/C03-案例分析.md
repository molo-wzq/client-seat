# 案例 C03:定期到期提醒,续存、活动权益与贵宾路径的联动

## 1. 场景

- 已知事实:客户B在某银行有一笔三年定期,12月6日(周六)到期,到期自动转活期;经理为其管户经理,本次为主动外呼提醒;当期续存利率约 1.75%;行内开门红活动:新资金 5 万以上给 50 元立减金+线下礼品,20 万→150 元,50 万→300 元;总资产 50 万以上为贵宾客户(生日礼、季度机场贵宾厅、节日礼品);客户透露他行有一笔资金约 1 月 15 日到期。
- (推测)客户到期资金的体量可能接近 50 万贵宾线,经理因此把贵宾权益作为钩子之一。

## 2. 客户状态(通话开始时)

- 态度:被动但配合——接话简短(「嗯」「可以的可以的」),无抗拒。
- 处境线索:有三年定期即将到期;他行还有一笔资金 1 月中到期(T11);对活动规则不熟悉(「新存进来是不是啊?」,T07)。
- 初始意愿:未表达明确意愿,倾向「按现状处理」。

## 3. 总体目标

到期资金续存;借开门红活动引导他行到期资金转入;以贵宾客户路径建立长期联系(约定 1 月再电联)。

## 4. 对话阶段

### 阶段 1:到期提醒 + 用途确认 + 利率定位(T02–T05)

| 字段 | 内容 |
| --- | --- |
| 阶段目的 | 以到期提醒建立服务正当性,确认资金用途后再谈续存 |
| 客户信号 | 「啊,对」(T03,确认身份);「可以的可以的」(T05,接受续存提议) |
| 推进逻辑 | 先报事实(到期日、自动转活期的后果)→先问用途(「短期内有用到吗」)→再给方案(续存+利率定位「现阶段算比较高的」)。顺序不能反:不问用途直接劝续存就是推销 |
| 关键动作 | ①自报管户身份+到期日提醒(含「自动转活期」的后果提示);②确认资金短期是否使用;③给出续存利率并做阶段内定位 |
| 代表话术 | 「它到时候会自动转活期上这样啊。然后您这个资金就是说,短期内,有用到吗?」(T04)——体现动作② |

### 阶段 2:活动权益分档报清 + 理解确认(T06–T10)

| 字段 | 内容 |
| --- | --- |
| 阶段目的 | 把活动权益讲清讲具体,并确认客户真的听懂了规则 |
| 客户信号 | 客户反问「就存到……新存进来是不是啊?」(T07)——暴露对「新资金」含义不确定 |
| 推进逻辑 | 分档报清(5万→50/20万→150/50万→300)之后不停留,主动核对客户理解;客户确认「新存进来」时立即放话(「理财、买定期都可以」),消除「只能存特定产品」的误解。活动介绍出现第二次(两遍转写一致,应为经理真实复述),对被动型客户是强调而非施压 |
| 关键动作 | ①场景化引入活动(开门红);②分档权益一次报清(档位+对应立减金);③主动核对理解+疑问即时解释(新存进来的范围) |
| 代表话术 | 「对对对,新存进来啊,你做理财、买定期都可以的。」(T08)——体现动作③ |

### 阶段 3:他行资金联动 + 贵宾路径 + 约定回访(T11–T16)

| 字段 | 内容 |
| --- | --- |
| 阶段目的 | 捕捉他行到期线索,把活动、贵宾权益与客户自身资产串成一条升级路径,并约定具体回访时间 |
| 客户信号 | 「哦,十五号左右吧,可能会有的」(T11,他行到期);主动核算「总额达到五十万是吧?」(T13);追问时间「那是在二月份吗?」(T15)——在意活动窗口 |
| 推进逻辑 | 客户说出他行到期时间后,经理不催转入,而是给身份激励:50 万总资产=贵宾客户+具体权益(生日礼/机场贵宾厅/节日礼品);客户自己开始算账(说明路径有效);最后把回访钉到「1 月 15 日前后再打电话」——与客户他行到期日绑定,下通电话有正事 |
| 关键动作 | ①记下他行到期时间并回扣(「一月有到期哦」);②贵宾门槛+具体权益一次报清;③约定与到期日联动的具体回访时间 |
| 代表话术 | 「一月有到期哦,一月是一月的几号?到时候我给您再打个电话,您看看,可以的话嘛,在我们这里再存一下,礼品也比较多。」(T16)——体现动作③ |

## 5. 优秀原因

1. **到期提醒带后果提示**(T04):「自动转活期」这一句让客户意识到不作为有实际损失——提醒本身创造需求,不需要渲染。对应 C03-SC1。
2. **先问用途再谈续存**(T04):确认「短期内不用」之后才报利率——顺序对了,续存就是服务而不是推销。对应 C03-SC1。
3. **分档权益报清 + 理解确认**(T06–T08):档位金额一次报清,并主动核对「新存进来」的含义——客户敢问、经理答得痛快,信任由此积累。对应 C03-SC2。
4. **重复强调但无施压**(T10):对被动型客户把关键活动复述一遍,信息重复但语气不加重——强调和催促的分寸感。
5. **把线索串成升级路径**(T11–T13):客户随口说的「他行 1 月到期」被立即接到贵宾客户路径上,客户主动开始算账(「总额达到五十万是吧」)——激励从经理嘴里转到客户心里。对应 C03-SC3。
6. **回访与客户节点绑定**(T16):回访时间不按经理方便,而按客户他行到期日定——下通电话自带正事。对应 C03-SC3。

做得一般、不值得复用的动作:

- T04 利率定位「现阶段算比较高的」属主观判断,若客户比价反显被动;建议只报数字,让客户自己定位。
- T10 重复活动介绍紧接在客户含糊回应之后,略显机械;可根据客户信号换角度强调(如只重复与他行到期相关的部分)。
- 录音尾部显示贵宾介绍有再启迹象(截断),若真实通话中反复展开贵宾权益,需注意分寸——以客户核算意愿为准。
