# 策略卡 SC-C01-2:只问现状,贴着回答找资金切入点

- 状态:草稿
- 来源案例:[C01-案例分析.md](C01-案例分析.md)(阶段 2–3)
- 来源片段:素材01 T02–T14
- 提炼人 / 日期:ZCode(代理办) / 2026-09-08

## 触发信号

- SC1 完成后客户愿意继续听(没有叫停);
- 客户对"资金放在哪/怎么打理"的问题开始给出实质回答——哪怕只是单字("没有");
- 客户主动透露任何资金习惯(炒股、买理财、放货基等)——这就是切入点的原材料。

## 适用场景

存量生客首次触达的中段:目的尚未落到具体产品,客户资金去向未知或只知道一部分;经理手里有一个与"资金效率/权益"相关的产品或活动可以后续对接。

## 当前目的

摸清客户资金的去向和打理习惯,找到客户自己说出的"可对比点",为下一步引发兴趣备料。

## 动作链

1. 开放式现状提问,一次只问一个("在其他银行有没有做过灵活资金的配置?")——先问配置现状,不提任何产品。
2. 接住每个回答并恭维具体化("今年市场好,您应该赚挺多")——让短句客户愿意多说,而不是查户口式连问。
3. 贴着回答往下钻一层("市场不好的时候,灵活资金放哪?")——从"买什么"逼近"闲置资金怎么处理",这里通常藏着机会成本。
4. 让客户自己说出习惯(T13"搞国债逆回购,T+1")——切入点必须来自客户口中,不是经理预设。
5. 先认可再对比("嗯,确实……不过我们银行也有 T+1,收益会高一些")——不否定客户现有做法,只指出效率差距;紧接把活动权益说具体(分档+对应金额)。
6. 引用客户自身情况制造相关性("我看您这个月资金也有提升")——把产品话题落回"您的情况"。

## 表达原则

- 现状阶段(动作 1–4)严禁出现产品名称和收益数字;
- 恭维要具体("今年市场好""收益率 20% 很厉害"),不空夸;
- 对比时先认可客户现有选择,再用"收益会低一些/高一些"这类相对表述,不贬低同业;
- 权益金额、分档一次说清,让客户能直接对号入座;
- 单轮不超过三句,给客户留接话空间。

## 参考话术

- 原话:"那您平常如果像这种就是在市场不太好的时候,会有一些这个灵活的资金嘛,那您一般都是选择直接放到那个证券里面吗?"(T12)
- 骨架:"那平时市场波动比较大的时候,您这部分灵活的钱一般是怎么安排的?也是直接放在〔客户说出处〕里吗?"
- 原话:"因为我看其实咱们这个月呢资金也有提升,只不过呢是放到这个证券账户的。就其实这样的话您也可以参加。"(T14)
- 骨架:"刚好我看到您最近〔资产线索〕,这笔钱目前放在〔客户说出的去处〕,其实您这种情况也能参加我们这个活动。"

## 适用条件

- 客户愿意回答现状问题(连续两个问题都得到回应);
- 经理对客户资金线索有基本了解或能在行内系统看到(资产变动、代发流水);
- 手里有可与客户现状对接的产品或活动,不会问完接不住。

## 停止条件

- 客户连续两轮只给单字回应且无新增信息 → 停止追问,直接给出本次来电的具体事由(转到具体活动/权益),或礼貌收口;
- 客户反问"你是不是要卖东西" → 不回避,如实说事由("是有一个活动想提前跟您说一声"),视回应决定继续或收口;
- 客户明确说"我不感兴趣" → 停止本卡,转体面收口路径,不做二次尝试。
