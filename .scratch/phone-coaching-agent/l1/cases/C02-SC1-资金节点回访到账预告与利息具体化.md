# 策略卡 SC-C02-1:资金节点回访——把到账变成服务接触点

- 状态:草稿
- 来源案例:[C02-案例分析.md](C02-案例分析.md)(阶段 1–2)
- 来源片段:素材02 T01–T07
- 提炼人 / 日期:ZCode(代理办) / 2026-09-08

## 触发信号

- 名下资金即将到账/到期,且此前已与客户有过沟通(有跟进的由头);
- 客户接听后允许继续说话(未拒绝)。

## 适用场景

存量客户维护:资金节点(到账、到期、发薪)前后的主动回访;经理对客户资金节点有台账级掌握,能报出具体数字。

## 当前目的

把资金节点转化为服务接触点,让客户主动说出资金安排与需求。

## 动作链

1. 征询接话时机(「方不方便接电话」)——维护电话也要给退路,不打断客户手头的事。
2. 到账/到期时间预告(「应该明晚到账」)——先给事实,让客户知道这通电话与自己的钱有关。
3. 利息具体化(「四千七百来块、两点七左右」)——不空说「不错」,数字让客户立刻感知价值。
4. 封闭式确认资金用途(「这钱是不用的,是不是啊?」)——让客户自己陈述安排,需求自然浮出;客户问什么就接什么,不抢答。

## 表达原则

- 数字必须具体(金额、利率、日期),一次报清;
- 确认用途用封闭问句,不开放式盘问;
- 客户主动提问后先短接(嗯/对)再展开,不显急切;
- 全程无产品名,需求由客户说出前不提任何配置建议。

## 参考话术

- 原话:「应该到账的话是明天的晚上这样子,十五万,利息的话还是蛮不错的哦,大概有四千七百来块。」(T03)
- 骨架:「您那笔钱〔具体日期〕到账,〔金额〕,利息大概〔具体数〕。」
- 骨架:「您这笔钱近期是用不到的吧?」——确认后停顿,把说话权交给客户。

## 适用条件

- 经理能准确报出到账/到期与利息数字(报错反伤信任);
- 客户与经理已有至少一次正向接触(跟进的前提);
- 客户接听后未表达拒绝。

## 停止条件

- 客户表示在忙/不方便→致歉收口,改约时间,不展开内容;
- 客户对数字无反应且连续单字回应→直接进入正题或礼貌收口,不复述数字;
- 客户明确表示资金另有安排且不想谈→认可现状,转维护型收口(见 SC-C02-3)。
