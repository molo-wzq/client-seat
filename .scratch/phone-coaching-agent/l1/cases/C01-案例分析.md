# 案例 C01:生客首次触达,从防备到同意报名并加微信

- 素材来源:[../transcripts/01-存量生客首次触达.md](../transcripts/01-存量生客首次触达.md)
- 素材检查:通过(见 [../transcripts/01-检查记录.md](../transcripts/01-检查记录.md))
- 分析人:ZCode(代理办)
- 分析日期:2026-09-08
- 素材类型:顺利沟通
- 提炼策略卡:C01-SC1、C01-SC2、C01-SC3(同目录)

## 1. 场景

- 已知事实:客户A是某银行代发工资客户(工资代发关系存续);本次通话为理财经理主动外呼,事先无预约;事由是行内针对代发客户的"拉新资金活动"(新资金分档给微信立减金权益);客户同时在某证券炒股,资金主要在证券账户。
- (推测)经理在拨号前已查看客户资产变动("我看其实咱们这个月呢资金也有提升",T14),说明触达名单经过筛选,不是盲打。

## 2. 客户状态(通话开始时)

- 态度:中性偏防备——接通后仅以单字回应("没有",T03),不主动展开。
- 处境线索:资金集中于证券账户炒股;对银行产品无既有配置。
- 初始意愿:未知。客户没有表现出需求,也没有抗拒。

## 3. 总体目标

让客户同意报名拉新活动,并建立后续联系渠道(加微信)——而不是当场卖出产品。

## 4. 对话阶段

### 阶段 1:建立身份可信度(T01–T02)

| 字段 | 内容 |
| --- | --- |
| 阶段目的 | 让客户确认"这是本行客户经理的正常服务来电",愿意继续听 |
| 客户信号 | 接通后安静等待(T01 前无回应);经理自述身份后客户未挂断 |
| 推进逻辑 | 陌生来电的默认反应是防备,先自报身份、说明信息来源(代发客户身份)和来意(有活动权益告知),并征询时机,把"是否继续"的选择权交给客户 |
| 关键动作 | ①自报身份+致意问候("早上好");②征询时机("您现在在忙吗?有空吗?");③说明身份依据("您是我们行的代发客户")与来意(有活动权益) |
| 代表话术 | "我是这个某银行您的客户经理。就是您现在在忙吗?有空吗?"(T01)——体现动作② |

### 阶段 2:判断沟通意愿、了解必要需求(T03–T13)

| 字段 | 内容 |
| --- | --- |
| 阶段目的 | 摸清客户资金的去向和习惯,找到产品与客户现状的连接点 |
| 客户信号 | "没有"(T03,其他银行无配置);短句回应但持续接话(T05/T06/T11);主动报出收益率"百分之二十"(T11);说出资金习惯"搞国债逆回购,T+1"(T13) |
| 推进逻辑 | 客户防备时不宜直接推产品;经理用开放式现状提问(其他银行有没有配置→收益率怎么样→市场不好时资金放哪)逐层接近资金真实状态,期间用恭维("您应该今年赚挺多钱")和共情市场波动维持对话温度。客户每给出一条信息,下一问就贴着该信息走 |
| 关键动作 | ①开放式现状提问(不推产品,只问"有没有/放哪里");②恭维并具体化("今年市场好,您应该赚挺多");③贴着回答追问资金安排("市场不好的时候,灵活资金放哪?") |
| 代表话术 | "那您平常如果像这种就是在市场不太好的时候,会有一些这个灵活的资金嘛,那您一般都是选择直接放到那个证券里面吗?"(T12)——体现动作③ |

### 阶段 3:引发兴趣(T14)

| 字段 | 内容 |
| --- | --- |
| 阶段目的 | 让客户意识到证券账户的资金存在"收益更低"的机会成本,对本行产品产生兴趣 |
| 客户信号 | 客户自己说出资金习惯:T+1 闲置资金做国债逆回购(T13)——这就是切入点 |
| 推进逻辑 | 不否定客户现有做法("嗯,确实"),先接住再对比:证券 T+1 收益低 → 银行有同类 T+1 短债产品且收益更高 → 叠加新资金活动权益(分档、具体金额)→ 结合客户本月资金变动说明"您也能参加"。全程站在"资金效率"角度,不是"买我的产品"角度 |
| 关键动作 | ①先认可再对比("确实……不过银行也有 T+1,收益更高");②把权益说具体(分档+对应立减金金额);③引用客户自身情况制造相关性("我看您这个月资金也有提升") |
| 代表话术 | "因为我看其实咱们这个月呢资金也有提升,只不过呢是放到这个证券账户的。就其实这样的话您也可以参加。"(T14)——体现动作③ |

### 阶段 4:争取合理下一步(T15–T26)

| 字段 | 内容 |
| --- | --- |
| 阶段目的 | 把兴趣落成具体承诺:报名活动 + 加微信,且不让客户感到被强制 |
| 客户信号 | "好的,可以"(T15,口头认同);犹豫"我那个钱要月底才到"(T17,担心要现在存钱);主动确认"那我不存进来也可以对不对"(T19,在做决定前核实自由度);同意加微信(T23) |
| 推进逻辑 | 用默认选项式提问推进("要不要先给您预约报名一下"),降低决策成本;T17 客户的犹豫暴露了误解(以为报名=现在转钱),经理立即消除障碍("31号之前资金不用转进来都可以参加"),而不是绕开疑虑;客户核实自由度时明确放行(T19"哎对"),再以"额度稀缺"轻推(有保留的紧迫感),最后落到加微信作为低成本下一步;收口预告后续服务并主动结束通话 |
| 关键动作 | ①默认选项式预约("要不要先给您预约报名一下 20 万那一档?");②异议即解释(客户说钱没到,立刻说明不用现在转钱);③明确给自由("我不存进来也可以——哎对");④落到低成本下一步(加微信);⑤预告后续服务并先说"不打扰"收口 |
| 代表话术 | "您看我这边要不要先给您预约报名一下20万的那一档?你看可以吗?"(T18)——体现动作① |

## 5. 优秀原因

1. **开场给退路**(T01):先问"在忙吗"再说来意,客户可以随时叫停——生客首触最常见的失败是被当成推销挂断,这个动作直接降低该风险。对应 SC1。
2. **只问现状、不推产品**(T02–T13):前两分钟全部用于了解资金去向,客户在无压力下主动给出了收益率、资金习惯两条关键信息——后续所有产品话术都建立在这两条信息上,而不是硬灌。对应 SC2。
3. **贴着客户的话找切入点**(T13→T14):客户自己说出"国债逆回购",经理立刻把"收益低一些"变成对比素材——切入点来自客户口中,说服成本最低。对应 SC2。
4. **权益具体化**(T14):分档+对应金额一次说清,客户马上能算出自己那一档值多少,比"有丰富权益"这类空话有效。对应 SC2。
5. **默认选项式推进 + 异议即解释**(T16–T18):"要不要先给您报名"把决策从"要不要参加"简化为"要不要我帮您办";客户表达犹豫后立即解释规则,消除"要现在转钱"的误解——异议没有被跳过。对应 SC3。
6. **明确确认客户自由**(T19→T20"哎对"):客户核实"不存进来也可以吧",经理痛快放行并补充"下个月也行"——正是这个放行让客户随后同意报名。高压话术在这里通常选择模糊回应。对应 SC3。
7. **把结果落到关系而非成交**(T20–T24):本通电话的"成交"是报名+加微信,经理额外预告了代发专属权益的后续通知,把一次性推销转化为长期服务关系。对应 SC3。

做得一般、不值得复用的动作:

- T07 经理以"嗯"回应客户"挺多的"后接"您今年的收益率是怎么样"——连续追问收益率略显查户口,可以更自然(如先接"挺多的"再顺势问)。
- T20"额度稀缺、需要提前抢占额度"带紧迫感,与全通低压风格略有张力;未造成伤害,但新对话复用时建议弱化。

## 6. 实际结果

- 客户同意经理代为报名 20 万档拉新活动(资金月底到账亦符合活动规则)。
- 客户同意加经理微信(T23),建立后续联系渠道。
- 通话自然收口,全程约 5 分钟,客户无任何拒绝表达。

## 7. 可复用条件

适用前提:

- 存量关系客户(代发/已有账户),与本经理无既有接触;
- 经理能看到基本资产线索(如本月资金变动),触达事由具体(活动/权益),不是空泛"维护";
- 客户资金有明确去处(他行/证券/理财),存在可对比的"效率差距"或可领取的权益。

不适用:

- 客户此前已明确拒绝过同类推荐(防御基线更高,需先处理旧印象);
- 无具体事由的纯寒暄外呼(本案例的合法性来自"告知活动权益");
- 客户在通话中表现出明显不耐烦或负面情绪(应先转 SC1 的收口路径)。
