# 素材04:生客首次触达·软拒绝(合成)

> **合成素材(ADR 0003 追加决议 8)**:本稿由代理起草,非真实录音转写。用途:L1 拒绝场景结构示范 + L2 对话验证;**不提炼产品种子策略卡**。
> 已脱敏:客户为虚构(客户C,某银行代发客户),机构名为通称(某银行)。

T01 经理:喂,客户C您好,我是某银行的客户经理,您现在说话方便吗?
T02 客户C:呃,正忙着呢,你哪个银行的?
T03 经理:某银行的。就一分钟,有个代发客户的活动跟您说一声,说完您接着忙。
T04 客户C:行,你说。
T05 经理:是这样,您是我们行的代发客户嘛,月底前有个新资金活动,资金放进来有微信立减金,五万档五十,二十万档一百五。不着急的话,您到时候看看。
T06 客户C:哎呀,再说吧,我这钱都有安排的,暂时不考虑啊。
T07 经理:理解理解,您钱都有安排那是好事。那不催您,这活动每个月都有,您什么时候有闲钱了都来得及。
T08 客户C:嗯嗯,到时候再看吧。
T09 经理:行,那这样,我微信上把活动说明发您一份,您有空翻翻就行,不用回复我。
T10 客户C:……行吧,你发过来吧。
T11 经理:好嘞,那就不多打扰您忙了。之后有适合您的消息我微信上说一声。您先忙,再见。
T12 客户C:嗯,再见。
