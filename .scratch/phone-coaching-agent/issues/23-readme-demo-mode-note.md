# 23: README 说明演示模式

**What to build:** 在 README 运行说明中说明「未配置模型 key 时为脚本演示模式」,让新用户能分辨假经理与真实模型。

**Blocked by:** None.

**Status:** ready-for-human

## 用户问题

未配置 `MIMO_API_KEY` 时,服务端静默切换到内置脚本化的 `FakeModelAdapter`(仅 console.warn),经理回复是固定脚本。界面上毫无标识,演示者/新用户无法分辨「假经理」与真实模型,可能把脚本应答当成模型能力。

## 改动范围

- 仅改 README「运行」相关章节:补一句说明——未配置模型 key 时应用以演示模式运行,经理由内置脚本扮演、应答固定;配置 key 后为真实模型应答。
- 不新增 `/api/meta` 端点、不动产品缝、不在界面加标识(用户已拍板)。

## 前后对照验收

- 前:README 运行章节未提演示模式。
- 后:读者能从 README 知道未配 key 时是脚本演示模式,以及如何配置切换到真实模型。
