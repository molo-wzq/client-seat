# 01: 建立可运行的核心骨架

**What to build:** 建立一条最短但完整的用户路径：用户提交一段示例转写稿，得到可确认发布的基础策略卡，随后以默认生客身份输入“喂”并完成一段模拟对话，最后看到本轮引用的策略。该任务同时建立可重复运行的最高层产品测试入口。

**Blocked by:** None (can start immediately).

**Status:** ready-for-human

实现口径见 spec.md 与 ADR 0002:种子内容为 C01 三张策略卡、P01 画像、一张虚拟产品卡;语言模型经适配器接入,端到端测试使用伪实现。

- [x] 产品能够本地启动，并提供素材、画像、对话和结果四个连续步骤。
- [x] 示例转写稿能够产生一张结构化策略卡，并从草稿变为已发布。
- [x] 默认生客输入“喂”后能够完成一段可结束的文字对话。
- [x] 结果能够显示本轮使用了哪张已发布策略卡。
- [x] 一条自动化产品测试覆盖从转写稿输入到结果追溯的完整路径。
