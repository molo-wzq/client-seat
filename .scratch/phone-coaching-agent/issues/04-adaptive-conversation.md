# 04: 实现策略驱动的自适应对话

**What to build:** 用户输入“喂”后，AI 始终以理财经理身份回应，根据客户最新信号更新当前目标、选择已发布策略并生成简短自然的电话表达。对话能够处理软拒绝、明确拒绝、合理推进、虚拟产品进入条件和结束边界。

**Blocked by:** 02: 完成策略提炼与人工发布; 03: 完成可见与隐藏的生客画像.

**Status:** ready-for-human

实现口径见 spec.md:对话生成以单次模型调用加结构化提示词实现四步,结束条件由提示词规则加应用层轮数上限表达;`l2/manager-prompt.md` 为参照实现,其中两处已知表达瑕疵须在正式提示词中修正。

- [x] AI 只能检索与当前场景、客户信号和目标相符的已发布策略。
- [x] 每轮回复只完成一个主要沟通动作，并保持理财经理角色。
- [x] 客户软拒绝时 AI 先降低压力，明确要求结束时 AI 礼貌收口。
- [x] 对话在达成合理下一步、无法继续或达到轮数上限时结束。
- [x] 未满足需求了解条件时 AI 不进入产品介绍。
- [x] 进入产品介绍后，AI 只使用固定虚拟产品卡中的事实。
- [x] 测试断言角色、边界、策略引用和事实来源，而不要求逐字输出一致。

实现说明:候选策略全量注入、由模型按信号选择(spec 决策);落库的 usedCardId 双重约束——伪/真适配器只引用本轮候选集内的卡,核心层再过滤一次。提示词在 l2 参照上新增软拒绝降压与产品门槛两条硬性规则,两处已知瑕疵(开场来意含糊、分档曲解)已修正。测试覆盖角色、软拒绝/明确拒绝/连续软拒绝(策略无法继续)/轮数上限四类边界、产品门槛与事实来源、未发布卡不可引用、隐藏信息输出层回归。
