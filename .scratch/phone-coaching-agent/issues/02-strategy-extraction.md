# 02: 完成策略提炼与人工发布

**What to build:** 用户提交真实电话转写稿后，系统按固定结构提炼场景、客户状态、目标、阶段、逻辑、关键动作、代表话术和适用条件；用户能够纠正说话人、修改分析内容，并明确决定是否发布策略。

**Blocked by:** 01: 建立可运行的核心骨架.

**Status:** ready-for-agent

实现口径见 spec.md:素材输入仅支持粘贴转写稿(音频为 L4);说话人区分与分析由模型适配器完成,测试使用伪实现;案例分析与策略卡结构以 `l1/` 模板为准。

- [ ] 系统能够区分理财经理与客户，并允许用户纠正错误角色。
- [ ] 分析结果包含规格定义的必需字段，无法确认的信息保持未知。
- [ ] 用户可以编辑分析结果并保存为草稿。
- [ ] 只有用户确认发布的策略卡能够被后续对话检索。
- [ ] 系统能够保留策略卡与原始转写片段之间的来源关系。
- [ ] 自动化测试验证草稿隔离、人工修改和发布行为。
