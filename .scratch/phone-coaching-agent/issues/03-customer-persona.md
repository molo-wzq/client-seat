# 03: 完成可见与隐藏的生客画像

**What to build:** 用户从预设画像开始，按需修改客户属性，并决定哪些信息对 AI 理财经理可见。未填写的信息必须保持未知，隐藏信息只约束客户角色，不得出现在理财经理的上下文中。

**Blocked by:** 01: 建立可运行的核心骨架.

**Status:** ready-for-agent

实现口径见 spec.md 与 ADR 0002:内置种子画像 1 个(P01),预设结构支持扩充;画像集扩充属 L1/L2 基础材料,延后补充。

- [ ] 用户可以从预设画像列表选择并修改部分属性;内置种子画像 1 个(P01),预设结构支持扩充。
- [ ] 所有画像字段均可留空，留空字段不会被系统自动补全。
- [ ] 用户可以区分 AI 可见资料和隐藏客户状态。
- [ ] 理财经理的对话输入中不包含隐藏画像内容。
- [ ] 自动化测试能够发现理财经理直接使用隐藏信息的行为。
