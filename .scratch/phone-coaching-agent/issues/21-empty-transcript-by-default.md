# 21: 新素材表单不预填种子转写稿

**What to build:** 新建素材时转写稿输入框为空,演示样例改为显式一键载入。

**Blocked by:** None.

**Status:** ready-for-agent

## 用户问题

新建素材时,转写稿输入框默认填入种子转写稿(`src/ui/MaterialStep.tsx:26` `useState(SEED_TRANSCRIPT)`):
- 用户粘贴自己的稿子前必须先全选删除;
- 不清空直接点「生成策略卡」会重复分析演示素材,制造重复的「素材01」。

## 改动范围

- `transcript` 初始为空字符串,占位符已存在,保持引导文案。
- 输入框旁提供「载入示例」次要按钮,点击一键填入种子转写稿,保住演示便利;仅对未开始分析的新素材显示。
- 同步调整依赖预填行为的测试(特别是 `App.test.tsx` 闭环测试,若其直接用预填稿点「生成策略卡」,需改为先输入或先点「载入示例」)。

## 前后对照验收

- 前:新建素材 → 输入框满屏种子稿。
- 后:新建素材 → 空输入框 + 占位符;点「载入示例」后填入示例稿;直接生成不会误分析演示素材。
