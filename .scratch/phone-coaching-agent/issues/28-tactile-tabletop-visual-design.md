# 28: 「理财经理电话牌桌」拟物视觉改版

**Type:** feature

**What to build:** 以 `docs/design/ui-asset-library-v1.md` 为视觉基准，把已实装的三幕结构从素样式升级为克制的纸张 / 木纹 / 呢绒牌桌界面；保持领域逻辑、信息架构和可访问性行为不变。

**Blocked by:** None.

**Status:** ready-for-human

## 已采用的实现决策

- 直接升级真实产品，不同步升级 `/?wireframe`；线框继续承担结构参照职责。
- 背景纹理由 CSS 渐变生成，不新增装饰图片与运行时资源依赖。
- 字体使用 Noto Sans SC / 思源黑体优先的系统字体栈，编号使用 Roboto Mono 优先的等宽栈；不请求远程字体。
- 装饰只用于左栏、结算和空态；对局信息区保持克制。
- 概念图的四阶段视觉只映射为 12 格轨道的四段着色，不改变轮次模型。

## 验收范围

- [x] 全局设计 token、纸张背景、木纹左栏与响应式外壳。
- [x] 布置幕：画像卡、客户席、策略卡、产品卡拟物化。
- [x] 对局幕：深绿桌面、画像明暗牌、分段轨道、对话气泡、当前策略高亮。
- [x] 结算幕与素材 / 策略 / 历史目录统一视觉语言。
- [x] 键盘焦点、拖拽 / 点击入座、按钮禁用态与既有文案契约保持。
