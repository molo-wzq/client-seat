# 10: AI 独立重拆复核与跨案例迁移

**Type:** task

**What to build:** 两道 L1 复核工序。其一:开不带先前结论的全新 AI 会话,对同一段素材(至少 C01 与一通新素材)重新拆解,与既有拆解做结构对照,出具复核记录。其二:把 C01 策略卡套用到新案例的背景上做跨案例改写(动作链原序原数保留、措辞全部重写),按 `transfer-examples.md` 的验证记录格式出具结论。

**Blocked by:** 07: 三通素材转写入库与拆解.

**Status:** ready-for-human

实现口径见 ADR 0003 决定 5、6:独立重拆是 demo 级复核,局限(非人类评分者、模型同源)必须写进复核记录;跨案例改写沿用 `transfer-examples.md` 既有格式(改写自、验证记录表、初步结论);复核发现的拆解结构歧义回写进模板建议,不在本票内改既有拆解结论。

- [x] 独立重拆会话完成(至少 2 段素材),对照记录入库 `l1/review/`(结构差异清单 + 是否支持"不同分析者可复现"的结论)。
- [x] 跨案例迁移改写完成(至少 1 张 C01 卡 × 1 个新案例背景),验证记录表齐备。
- [x] 两道复核的局限与发现汇总,模板改进建议(如有)单独成节。

实现说明:原计划用独立子代理重拆,因子代理额度上限改走真实模型 + 产品分析提示词(`l1/tools/independent-analysis.ts`)——模型无仓库先验,独立性反而更纯粹。素材01/02 独立拆解均复现人工版核心结构;素材02 暴露场景读法偏差(到账 vs 到期)与卡粒度分歧,已列入模板改进建议(见 `l1/review/复核记录-独立重拆.md`)。跨案例:SC1-C2 六步动作链完整迁移到素材03 背景(C01-SC2T2),改写过程反哺出 C03 卡集缺「前置探图景」步骤的提示(见 `transfer-examples.md`)。
