# 05: 完成策略解释与文本素材追溯

**What to build:** 一次模拟电话结束后，用户能够看到沟通结果、结束原因、实际策略路径和关键表达，并从每个关键动作回到所引用的策略卡及原始转写片段。结果页只解释 AI 的打法，不评价扮演客户的用户。

**Blocked by:** 04: 实现策略驱动的自适应对话.

**Status:** ready-for-human

实现口径见 spec.md:策略路径须能追溯到已发布策略卡与原始转写片段;结果页不出现任何用户评分或训练元素。

- [x] 结果页展示本轮目标、沟通结果和结束原因。
- [x] 策略路径与实际对话期间记录的动作一致。
- [x] 每个关键动作能够追溯到已发布策略卡和原始转写片段。
- [x] 结果页不出现用户分数、能力评价或训练题。
- [x] 使用不同生客画像时，结果能够反映实际采用的不同策略路径。
- [x] 最高层产品测试覆盖素材发布、模拟对话和结果解释闭环。

实现说明:策略路径条目直接由会话轮次派生(轮次号、卡 id、关键表达与轮次记录一一对应);来源片段按素材 id 定位(标题仅供人读,重名不错位)并以 `resolveTurnRange` 解析为原始轮次,结果页逐句展示,解析失败时明示"未能定位"而非静默;来源追溯限定已发布卡。不同画像的策略路径差异由领域级测试断言(P01 走 SC2,无资金线索画像跳过现状了解直接 SC3)。最高层测试(App.test.tsx)覆盖素材发布→模拟对话→结果解释闭环,并断言无评分元素。

已知边界:来源区间为卡级口径(卡的素材区间),不细分到单轮音频片段;文本素材追溯已满足当前产品需要,不再把音频片段定位延后到 L4。
