# 05: 完成策略解释与文本素材追溯

**What to build:** 一次模拟电话结束后，用户能够看到沟通结果、结束原因、实际策略路径和关键表达，并从每个关键动作回到所引用的策略卡及原始转写片段。结果页只解释 AI 的打法，不评价扮演客户的用户。

**Blocked by:** 04: 实现策略驱动的自适应对话.

**Status:** ready-for-agent

实现口径见 spec.md:策略路径须能追溯到已发布策略卡与原始转写片段;结果页不出现任何用户评分或训练元素。

- [ ] 结果页展示本轮目标、沟通结果和结束原因。
- [ ] 策略路径与实际对话期间记录的动作一致。
- [ ] 每个关键动作能够追溯到已发布策略卡和原始转写片段。
- [ ] 结果页不出现用户分数、能力评价或训练题。
- [ ] 使用不同生客画像时，结果能够反映实际采用的不同策略路径。
- [ ] 最高层产品测试覆盖素材发布、模拟对话和结果解释闭环。
