# 33 · 投研周报:首页抽屉挂载与总报告下载

Status: ready-for-human

## 背景

理财经理外呼前不仅需要掌握策略卡，还需要了解当周的宏观方向、行业轮动热点、重点推荐公募/理财池，以及应对客户行情顾虑的现成话术。调研并融合外部 `weekly-investment-report`（14 章深度投研框架）与本地 `weekly-invest-report`，不在通话主逻辑中硬塞长篇报告，而是采用**首页分段抽屉挂载 + 总报告下载**的设计，降低系统侵入性，每周仅需自动更新周报分段数据。

## 决定

- **首页抽屉化（SetupAct）**：移除原首页的四条通话规律（`LogicRail`），右栏替换为「投研弹药库」`ResearchDrawer`。按实战场景拆解为 4 个即查抽屉：
  1. `macro`（宏观与开场破冰）：核心研判一句话、大盘温度计、电销开场白；
  2. `sector`（行业轮动主线）：资金流入赛道、防御避险方向、热点应对建议；
  3. `product`（资产配置与产品推荐）：45/35/20 仓位矩阵、主推华夏智鑫纯债/工银添利宝等标的池速查、促成话术；
  4. `risk`（客户异议答疑）：客户问“行情差不敢买/利率低”的标准共情答疑卡、下周关注大事。
- **总报告下载**：
  - 首页右栏顶部提供「📥 下载完整周报」按钮；
  - 抽屉面板底部常驻下载链接；
  - 服务端提供 `GET /api/research/download`，支持下载当期 14 章完整 HTML/PDF 文档。
- **左侧导航（LeftRail）**：在资料分组下增加「投研周报」入口，可在应用内全屏查阅完整周报。
- **自动拆分与服务端支持**：
  - `src/domain/research-report.ts` 定义分段模型；
  - `server/report-parser.ts` 自动解析成稿提取分段存至 `data/reports/current-sections.json`；
  - `server/app-server.ts` 暴露 `GET /api/research/current` 与下载接口。
- **技能融合**：将附件 14 章框架合入 `C:\Users\65198\.zcode\skills\weekly-invest-report\`，保持 Windows 平台 Edge/Chrome headless PDF 渲染脚本兼容。
