# 票 31:AI 对话标配交互——快捷回复/停止生成/重新生成/复制

Status: ready-for-human

## 内容

主流 AI 产品的四件标配交互,补齐对局幕:

1. **快捷回复 chips**:输入框上方按局势切三组建议回应(接通/探询期/经理报产品后),
   点击即发。客户信号实体化,演示节奏快一倍。
2. **停止生成**:流式进行中发送键切换为砖红停止键;断流后乐观客户轮回滚、草稿恢复、
   静默无报错。服务端该轮可能仍落库(ponytail: 未做服务端模型调用取消,
   升级路径是把 req close 串到 adapter fetch 的 AbortSignal)。
3. **重新生成经理回复**:领域层 `regenerateManagerTurn`——丢弃最后一轮经理话术,
   以同一客户发言重摇,不追加客户轮、轮次号连续;与发送共用 `appendManagerTurn`
   落库路径(串行化/收口判定/检索边界校验一致)。仅通话进行中且末轮为经理话术时可用。
4. **经理话术复制**:气泡 hover 显示复制键(触屏常显),复制后 1.6s 显示"已复制"。

## 验证

- 152 测试全过(新增:领域 regenerate 3 例、HTTP 路由 2 例、chips/复制 UI 2 例)
- DeepSeek flash 实测:chip 直发首字 2.9s;重新生成 3.7s 无重复客户轮;
  停止断流回滚正常;chips 随经理话术在探询组/产品组间切换
