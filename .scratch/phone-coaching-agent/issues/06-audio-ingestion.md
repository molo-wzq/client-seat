# 06: 后台摄入优秀录音

**What to build:** 将优秀电话录音的慢速转写放到后台处理,生成带说话人的待校对转写稿,再进入现有素材提炼与发布流程。前端不提供录音上传、处理等待或原声回放。

**Blocked by:** 02: 完成策略提炼与人工发布; 05: 完成策略解释与文本素材追溯.

**Status:** ready-for-human

L4 范围改为后台录音摄入。当前采用显式 CLI 任务,单次处理一段本地录音并输出 Git 忽略的待校对稿;校对与脱敏后再人工交接到现有素材库。原声回放、音频片段定位、实时语音对练均不在范围内。

- [x] 后台任务可接收一段优秀录音,慢速转写不占用前端对局流程。
- [x] 产出带说话人的待校对转写稿,可交接到现有素材库流程。
- [x] 失败可重试且不会产生半成品素材。
- [x] 后台转写服务具有稳定的契约测试。
- [ ] 使用一段新录音完成后台转写到素材交接的验收。
