# 06: 接入单段录音转写与音频追溯

**What to build:** 用户能够上传一段中文电话录音，系统通过可替换的转写能力生成带说话人和时间信息的规范化转写，并进入现有策略提炼、发布、对话和结果解释流程；结果中的策略来源可以定位到对应音频片段。

**Blocked by:** 02: 完成策略提炼与人工发布; 05: 完成策略解释与文本素材追溯.

**Status:** needs-info

L4 范围:音频上传与转写接入不在本轮 L3(见 spec.md Out of Scope 与 ADR 0002),L3 完成后重新评估。

- [ ] 用户可以上传单段支持格式的中文电话录音并看到处理状态。
- [ ] 转写结果包含说话人轮次和可用于定位原音频的时间信息。
- [ ] 用户能够纠正说话人后重新生成或更新策略分析。
- [ ] 转写服务通过独立适配器接入，失败时不会破坏已有素材。
- [ ] 结果页中的策略来源能够播放或定位到对应录音片段。
- [ ] 转写适配器具有稳定的契约测试，核心产品测试不依赖实时外部服务。
- [ ] 使用一段新录音完成从上传到新对话策略复用的完整验收。
