# 06: 更方便地摄入优秀录音

**What to build:** 用户能够直接上传一段中文优秀电话录音,系统通过可替换的转写能力生成带说话人的规范化转写,并进入现有策略提炼与发布流程。L4 只降低优秀录音进入素材库的成本,不扩展对练或结算形态。

**Blocked by:** 02: 完成策略提炼与人工发布; 05: 完成策略解释与文本素材追溯.

**Status:** ready-for-human

L4 范围:录音上传与自动转写。原声回放、音频片段定位、实时语音对练均不在范围内。功能未实现前不在主界面放禁用占位。

- [x] 用户可以上传单段支持格式的中文电话录音并看到处理状态。
- [x] 转写结果包含说话人轮次,可直接进入现有素材编辑流程。
- [x] 用户能够纠正说话人并沿用现有分析编辑能力修正策略分析。
- [x] 转写服务通过独立适配器接入，失败时不会破坏已有素材。
- [x] 转写适配器具有稳定的契约测试，核心产品测试不依赖实时外部服务。
- [ ] 使用一段新录音完成从上传到新对话策略复用的完整验收。

## Comments

- 2026-09-09 用户重新收窄 L4:只要“更方便地摄入优秀录音”;回放录音没有必要,设计保持精简。删除原声回放、时间片段定位要求,也不提前放置禁用入口。
- 2026-09-09 实现完成(待人工录音验收):支持 mp3/m4a/wav/webm/ogg,单段上限 25MB;浏览器以二进制上传,服务端通过独立 `AudioTranscriptionPort` 调用 `mimo-v2.5-asr`,只返回待校对文字,不保存录音。未配置密钥时伪适配器支持本地演示。73 项自动测试通过,其中包含“转写→分析→发布→新对话”产品缝闭环;真实录音不进测试仓库,最后一项由人工选择本地录音验收。
