# 实体桌游皮肤（方向 A）

像一盒印刷精良的实体桌游：米白卡纸、墨绿桌垫、扁平配色。只换皮、不改玩法，词汇沿用 CONTEXT.md。

- 克制：不用发光、金属渐变、厚木框；层次只靠纸张、细线和轻阴影。
- 场景：页面是米色亚麻桌布；左栏墨绿纯色，当前项是一张米白卡；牌桌是墨绿桌垫加一圈米白细线。
- 颜色：砖红 = 主操作/结束；金色 = 计数与走过的轮次；藏青 = 隐藏牌与探询；翡翠绿 = 开场/已发布；芥黄 = 产品。
- 策略卡：卡纸 + 色块插画条（`CardArt` 代码绘制，按开场/探询/产品/收口取色）+ 左上编号圆标；策略卡页、布置幕迷你卡、对局右栏共用。对局里亮出的明牌加金色描边。
- 人物：生客名册是角色卡，头像为米白圆框加墨绿细圈；入座的卡加金色描边。
- 隐藏牌：藏青卡背斜纹 + 锁形标记，仅玩家可见的语义不变。
- 通话轨道：桌游计分格，走过涂金，当前格砖红描边，第 12 格浅砖红提示收口。
- 实现：`src/ui/tabletop-skin.css` 最后加载；卡牌节点增加 `data-gem` / `data-status` 与插画节点，不改领域与状态逻辑。保留出牌动画与减少动画偏好。
- 验收：类型检查、全部测试、构建；1440 与 390 宽度视觉检查。
