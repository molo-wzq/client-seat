# UI 素材库 v1 ——「理财经理电话牌桌」视觉方向

**配图**: [ui-asset-library-v1.png](./ui-asset-library-v1.png)（AI 生成概念图，2026-09-09 评审，美术方向通过）

## 定位与使用规则

- 票 16 三幕结构实装时明确「拟物质感 / 新配色」另立工作，本素材库即那件工作的视觉基准。
- 概念图为 AI 生成：**版式、质感、配色氛围可信；图上文字不可直接照抄**（glitch 汉字与占位文案见 §7 更正记录）。
- 冲突时的优先级：`CONTEXT.md` 领域词条 > 本文档 token > 概念图文字。
- 实现基准是本文档的 token 与规格，不是图的像素；图用于对氛围（纸感、呢面、做旧、手绘 doodle）。

## 1. 设计 token

```css
:root {
  /* 主色 —— 图上印刷值，已逐格核对 */
  --felt-deep:    #0F2D1F; /* 深绿：桌面呢绒、主要按钮、页眉 */
  --brick-red:    #CC092B; /* 砖红：危险按钮、错误提示、印章、策略卡框 */
  --warm-yellow:  #F4D06F; /* 暖黄：当前阶段、提示、R3 徽章 */
  --ink-blue:     #2E5BFF; /* 深蓝：AI 理财经理、策略卡横幅 */
  /* 辅色 */
  --paper-white:  #EDE0D9; /* 米白：卡纸亮部 */
  --khaki-light:  #D1C6B2; /* 浅卡其：分隔、次级底色 */
  --gray-mid:     #6B6B8B; /* 中灰：禁用、次级文字 */
  --ink-black:    #1A1A1A; /* 黑：正文、隐藏信息卡 */
  /* 取样补充 —— 图上未印色号，取自像素采样 */
  --page-paper:      #E5D8C6; /* 页面纸底（取样 #E0D1BF ~ #E4D9CB） */
  --card-paper:      #EBE0CE; /* 卡片纸底（取样偏暗，适度提亮） */
  --bubble-customer: #ECE9E2; /* 客户气泡米白（取样 #DDDAD4） */
  --bubble-ai:       #D8E3F0; /* AI 气泡浅蓝（取样） */
  /* 背景纹理基色（§5，取样） */
  --tex-felt:  #364536; /* 深绿呢绒 */
  --tex-wood:  #4D3624; /* 深木纹 */
  --tex-linen: #BEAF9D; /* 米纸纹理 */
  --tex-grid:  #242E27; /* 深绿格纹 */
}
```

注：AI 渲染的色块比印刷值偏灰偏柔（砖红渲染实测 `#A53C2B`、深蓝 `#2E52A2`），实现以印刷值为准，偏差是图的瑕疵不是设计意图。

## 3. 组件规格

### 按钮（图 §3）

| 变体 | 底色 | 示例文案 |
| --- | --- | --- |
| 主要 | 深绿 | 接通电话（图作「开放通话」，按领域词条更正，见 §7） |
| 危险 | 砖红 | 结束通话 |
| 次要 | 纸底 + 黑描边 | 下一回合 → |
| 幽灵 | 透明 + 描边 | 重置训练 ↻ |

状态四阶：默认 / 悬停 / 点击为深绿由深到浅，禁用为中灰。小圆角（4–6px）+ 轻投影，拟物但不夸张。

### 徽章（图 §4）

- **身份**：客户（深绿）/ AI 理财经理（深蓝）/ 隐藏信息（砖红 + 锁）
- **状态**：已发现（绿勾）/ 未发现（红问号）/ 当前阶段（暖黄靶心）/ 提示（灰灯泡）
- **沟通目的五类**：破冰（藏青）/ 探询（青）/ 安抚（绿）/ 推进（橙）/ 收口（琥珀）——这里只取**视觉规格**，实际文案跟随策略卡数据（`currentGoal`），不硬编码
- **风险**：R1 低（灰）/ R2 中低（浅灰）/ R3 中（暖黄）/ R4 中高（橙）/ R5 高（红）

### 卡片（图 §5–7）

- **客户卡**：米白纸底 + 双线做旧边框；头部等宽编号（`CLIENT #017`）；手绘风头像；属性行（年龄 | 职业）；标签徽章 ×2；引语区。
- **隐藏信息卡**：黑底反白，锁形图标 + `???`，注「通过对话逐步挖掘」。实机语义按票 16 为「扣着但可看」，文案用「仅你知情，AI 不可见」。
- **产品卡**：卡纸底 + 暖色双线边框，右上书签绶带；手绘图表 doodle；要点列表；页脚一句口号。
- **策略卡**：砖红双线框 + 深蓝横幅（卡名）+ 大字插画 + 一句话要义 + 等宽编号（`CASE / 02`）。卡名与编号来自素材提炼，图上为占位。

### 对话气泡（图 §8）

客户 = 米白气泡，AI 理财经理 = 浅蓝气泡（`--bubble-ai`）；左侧头像 + 身份徽章，右下等宽时间戳。

### 进度（图 §9）

- **阶段 stepper**：完成 = 绿勾，当前 = 砖红实心数字，未到 = 灰。概念图为 4 段语义阶段（建立关系 / 深入探询 / 方案沟通 / 收口确认），实机对局幕是 **12 格通话轨道**——把四段作为轨道的分段着色语义，不照搬 4 格。
- **时长条**：`04:32 / 10:00`，深绿填充。
- **隐藏信息发现进度**：分段块 `1 / 3`。

### 弹窗 / Toast（图 §11）

- 隐藏信息揭示 modal：纸底卡 + 绿勾标题 + 引语 + 主要按钮「继续」。
- 成功 toast 绿：「策略使用成功，客户态度放缓！」；失败 toast 红：「客户产生抗拒情绪，请调整策略！」——均为示例文案。

## 5. 背景纹理与装饰（图 §12–13）

- **纹理四格**：深绿呢绒（对局桌面）/ 深木纹（外框或侧栏）/ 米纸（卡纸质感）/ 深绿格纹（结算或留白区）。
- **装饰元素**：便利贴标语、`CONFIDENTIAL` 红章、回形针、钢笔、咖啡渍、绿叶——克制使用，只用于结算幕与空态插画，**不进对局信息区**。
