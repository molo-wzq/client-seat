# Client Seat 参赛使用说明

> 银行客户视角智能沟通对练平台  
> 公开仓库：[https://github.com/molo-wzq/client-seat](https://github.com/molo-wzq/client-seat)

## 一、作品简介

Client Seat 是一款面向银行理财经理的 AI 沟通训练产品。它把一次电话服务设计成可观察、可复盘的策略牌局：AI 理财经理依据团队审核发布的策略卡推进对话，员工坐到“客户席”，扮演具有明确背景、真实顾虑和隐藏想法的虚拟客户。

产品并不要求员工机械背诵标准话术，而是帮助员工从客户感受出发，判断一句开场是否愿意让人听下去、一次探询是否过急、一次推进是否合适，以及何时应该体面收口。

## 二、为什么由员工扮演客户

传统话术训练通常让员工扮演理财经理、AI 扮演客户，重点是练习“怎么说”。Client Seat 反转角色，重点训练“客户为什么愿意听”。

员工站在客户一侧，可以直接体验不同服务策略带来的心理感受；AI 理财经理则成为团队方法的可执行载体。每次对局既是一次客户视角训练，也是对策略卡质量的检验。好的服务经验因此能够被发布、使用、复盘和持续优化，逐步沉淀为团队能力。

## 三、核心体验

1. **选择生客**：从生客名册选择一位虚拟客户。明面信息模拟经理可见的行内背景，隐藏牌只对客户扮演者可见。
2. **配置牌桌**：已发布的策略卡与产品卡共同限定 AI 理财经理的行动空间和事实边界。
3. **接通电话**：员工以客户身份回应，AI 理财经理根据对话信号选择策略，十二格通话轨道控制对局节奏。
4. **查看战报**：结束后回看逐轮策略路径、关键判断和素材出处，判断哪些做法值得保留或调整。

### 策略是怎么提炼出来的

策略卡不是人工凭空编写，也不是模型直接生成，而是一条「真实通话 → 半自动提炼 → 人工确认」的流水线：

1. **录音转写**：优秀通话录音经后台转写，按说话人整理成带轮次编号的待校对稿，人工核对并脱敏后才可用。
2. **模型提炼**：素材分析输出结构化案例分析与 1–3 张策略卡草稿，每张卡自带来源轮次区间（如 T04–T14）、触发信号、动作链、表达原则、参考话术与停止条件。
3. **人工发布**：在素材库中纠正说话人、编辑卡面，逐张确认发布；草稿永远进不了对局。
4. **对局引用与回溯**：AI 每轮只看到已发布卡；它声称使用的卡会经系统校验确在本轮已发布集合内。结算页把每轮用卡回溯到原始通话片段，形成「经验 → 卡 → 对局 → 复盘」闭环。

## 四、快速启动

### 环境要求

- Node.js 20 或更高版本
- npm

### 安装和运行

```bash
npm install
npm run dev
```

默认访问地址：

- 前端：`http://localhost:5173`
- 本地 API：`http://localhost:5175`

如果 5173 已被占用，Vite 会自动选择下一个可用端口，请以终端输出为准。

### 配置真实模型（可选）

在项目根目录创建仅供本机使用的 `.env.local`：

```dotenv
MIMO_API_KEY=你的密钥
MIMO_BASE_URL=模型服务地址
MIMO_MODEL=模型名称
```

`.env.local` 已被 Git 和参赛打包流程排除。未配置密钥时，系统使用内置脚本化经理完成演示；该模式用于验证交互流程，不代表真实模型效果。

## 五、建议演示路线

1. 打开“新对局（布置）”，展示生客名册、客户席、策略卡与产品卡。
2. 选择“代发·资金在证券”客户并入座，说明明面信息与隐藏牌的差异。
3. 接通电话后以客户身份回复，观察 AI 理财经理选择的策略及通话轨道变化。
4. 至少完成一次拒绝或追问，展示系统如何调整推进方式。
5. 结束对局并打开战报，展示逐轮策略路径和素材追溯能力。

完整演示建议控制在 4 至 6 分钟。

## 六、AI 与安全边界

- AI 理财经理只使用人工确认并发布的策略卡，不擅自把模型生成内容写回团队方法库。
- 产品卡限定产品事实，避免 AI 为了推进对话而补造活动信息。
- 模型密钥只在本地服务端读取，不进入浏览器、GitHub 仓库或参赛 ZIP。
- 原始录音、未脱敏转写、客户数据和内部复核材料不进入参赛包。
- 无模型密钥时自动进入明确的演示模式，便于评委本地查看完整交互。

## 九、常见问题

**为什么 AI 不扮演客户？**  
本作品的差异化目标是训练客户视角并验证团队策略。员工亲自坐到客户席，才能感受服务动作对客户心理的真实影响。

**没有模型密钥能否演示？**  
可以。系统会使用内置脚本化经理完成基础流程，但正式展示 AI 推理能力时建议配置真实模型。

**是否需要安装数据库？**  
不需要。当前版本使用本地文件存储，适合海选演示和原型验证。

**如何查看最新源码？**  
访问公开仓库：[https://github.com/molo-wzq/client-seat](https://github.com/molo-wzq/client-seat)。
