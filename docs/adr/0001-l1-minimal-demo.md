# ADR 0001:L1 以最小 demo 标准收口,直接进入对话 demo 验证

日期:2026-09-08
状态:已接受(用户决策)

## 背景

L1(素材知识化验证)的原始验收标准要求:3–5 段素材覆盖顺利沟通、软拒绝、明确拒绝,并由不同分析者独立拆解复核。目前已完成 1 段顺利沟通素材(素材01)的完整拆解(1 份案例分析 + 3 张策略卡)和单案例迁移改写。

用户于 2026-09-08 决定:不再补充其他录音,不做独立拆解复核,当前按**最小 demo 版本**推进。

## 决定

1. L1 按最小 demo 标准收口:软拒绝/明确拒绝素材与独立分析者复核**延后**,不阻塞后续工作。
2. 当前策略资产 = C01 案例分析 + 三张策略卡(SC1/SC2/SC3),是 demo 阶段唯一的策略来源。
3. 下一步为 L2 的最小 demo:用策略卡驱动 AI 理财经理,以**控制台文字对话**(脚本属于验证工件,不是 L3 Web 产品实现)验证价值链"素材 → 策略卡 → 新对话 → 策略解释"。
4. 在 demo 验证通过前,仍不进入 Web 产品实现(L3)、不接入转写服务到产品、不扩展场景。

## 影响

- L1 验收标准部分豁免,剩余项在 roadmap 中标注"延后"而非"完成";
- 策略卡库仅覆盖顺利沟通一类场景,面对强拒绝客户的策略缺失是已知限制,demo 中若遇明确拒绝应走通用"接住—收口"路径;
- 迁移性验证停留于单案例自我改写,demo 对话中若发现策略卡照抄原话或无法适配新背景,应回补 L1 缺口。
