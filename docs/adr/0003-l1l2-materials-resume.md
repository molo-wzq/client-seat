# ADR 0003:重启 L1/L2 基础材料扩充,以三通真实录音为源

日期:2026-09-08
状态:已接受(用户决策)

## 背景

L3 最小产品闭环已完成(issues 01–05 交付)。ADR 0002 延后的 L1/L2 基础材料(软拒绝/明确拒绝素材、独立分析者复核、跨案例迁移复核、3 画像集、代表性对话集)恢复推进。用户于 2026-09-08 逐项决策如下。

## 决定

1. **素材来源:用户提供 3 通真实电话录音**(音频文件投放至 `l1/audio/`),由代理转写、脱敏、检查、拆解。场景不预设;真实素材拆解后若仍缺「软拒绝」或「明确拒绝」类型,代理再向用户确认是否以合成素材补缺口。
2. **合成素材标准(备用,尚未启用)**:如经用户批准起草,合成转写稿须明确标注"合成/待真实素材替换",照常走质量检查表;**不得提炼为产品种子策略卡**,只作 L2 验证与 L1 结构示范。
3. **画像:从三通录音中的真实客户提取**,替换"AI 自拟画像"方案;提取后**做进产品内置种子**(种子画像由 1 个扩为 3 个),spec 相应条目同步修订。
4. **代表性对话集:真模型 + 产品当前提示词**(`src/adapters/prompts.ts`,非旧版 `l2/manager-prompt.md`),3 个新画像各录一通,客户轮次按画像性格脚本化;按 `demo-conversation-01.md` 格式存档三段。
5. **独立分析者复核:以"AI 独立重拆对照"作 demo 级复核**——开不带先前结论的全新会话重拆同一段素材,与既有拆解做结构对照,局限(非人类评分者)写进复核记录;真人复核标准保留给 L5 试用前。
6. **跨案例迁移复核**:在三通素材拆解完成后执行——把 C01 策略卡套用到新案例背景,验证动作链的跨案例可执行性。

## 追加决议(2026-09-08,三通录音入库后)

用户提供的第三通录音经核对与素材01 同源;另两通均为「存量客户维护」性质(跟进触达、到期续存),且均未覆盖拒绝场景。据此追加:

7. **A3 口径修订(用户决策)**:素材准入从「仅存量生客首次触达」放宽为「首次触达或存量客户维护(到期提醒、跟进回访等)」,检查表已同步修订;素材类型归档相应扩展。
8. **合成素材启用(用户批准)**:拒绝场景素材缺口由代理起草合成转写稿补齐(软拒绝、明确拒绝各一通),明确标注「合成」,照常过检查表;只作参考与 L2 验证,不提炼产品种子策略卡。
9. **画像来源确认**:三个内置画像 = P01(素材01)+ 素材02 客户A + 素材03 客户B,均提取自真实素材;对话演示(票 09)所需的推脱/拒绝客户画像为合成验证件,只作 L2 演示用,不入产品种子。

## 追加决议(2026-09-08,验收阶段)

10. **新拆策略卡暂不入产品种子(用户决策)**:C02/C03 从真实素材提炼的 6 张卡维持草稿态,只作 l1 材料;产品种子策略库保持 SC1–SC3。何时入种子待定(候选触发:用户明确要求、L5 试用反馈)。合成拒绝卡按决议 8 永不入种子。
11. **验收结论待用户细看**:验收清单见 `.scratch/phone-coaching-agent/acceptance-checklist.md`;材料线(素材口径、合成台词、画像描述、演示记录)与产品线(01–05)均在 ready-for-human 等待逐项确认。

## 影响

- 产品内置种子画像将由 1 个扩为 3 个,spec「内置种子画像 1 个(P01)」条目失效;
- 新素材的拆解产物(案例分析、策略卡)按既有模板与检查表入库;是否将新案例的策略卡加入产品种子策略库,待拆解质量确认后另行决策(默认:新素材优先用于画像提取与 L2 验证,种子策略库仍为 SC1–SC3);
- 「素材类型」(顺利沟通/软拒绝/明确拒绝)成为入库档案的必填归档项;
- 真实录音与未脱敏转写不进 git(`l1/audio/`、`transcripts/_unscreened/` 已 gitignore)。
