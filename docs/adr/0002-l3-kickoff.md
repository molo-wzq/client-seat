# ADR 0002:进入 L3 实现,L1/L2 基础材料留空延后补充

日期:2026-09-08
状态:已接受(用户决策)

## 背景

L1 按最小 demo 标准收口(ADR 0001),L2 最小 demo 已跑通价值链(素材→策略卡→新对话→策略解释)。用户于 2026-09-08 决定进入 L3 最小产品闭环的实现。

## 决定

1. **进入 L3 实现**,按 spec.md 与 issues/01–05 执行;06(音频接入)属 L4 范围,本轮不做。
2. **L1/L2 基础材料留空,后续补充**,不阻塞 L3:
   - L1:软拒绝、明确拒绝类素材;跨案例迁移复核;独立分析者复核;
   - L2:3 画像集、三类生客代表性对话集、独立对话状态机;
   - demo 发现的两处表达瑕疵(开场来意偏含糊、"每新增5万"对分档规则有曲解)在实现提示词中收紧,不回炉 L1。
3. **种子内容**:MVP 素材库冷启动内容为 C01 案例的三张策略卡(SC1/SC2/SC3)+ P01 生客画像 + 一张虚拟产品卡;产品结构支持多素材多画像,初始数据即此种子集。

## 影响

- 策略库初始只覆盖"顺利沟通"一类场景,强拒绝场景走通用"接住—收口"路径,质量未验证;
- 画像预设初始只有 1 个,产品须支持预设列表扩展;
- 后续补充 L1/L2 材料时,产物仍按 `.scratch/phone-coaching-agent/l1/`、`l2/` 既有模板与检查表入库。
