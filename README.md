# 电话对练

让银行理财经理在真正拨号前，先把一通难开的电话练明白。

你可以选择不同的客户画像，与 AI 完成一通接近真实场景的电话：怎么开场不冒犯、怎么发现需求、什么时候该推进、被拒绝后如何体面收口。每次练习结束后，系统会还原本通电话使用的方法，帮助你把“凭感觉”逐渐变成可复用的能力。

## 你可以用它做什么

- **从优秀通话中沉淀方法**：把经过校对的电话转写稿整理成清晰、可复用的策略卡。
- **练不同类型的客户**：带着客户背景和本通目标进入情境，不只背一套固定话术。
- **完成一通真实感对话**：AI 扮演理财经理，你从客户视角回应，观察策略在通话里的实际表现。
- **回看这通电话为什么这样说**：结果页会关联本轮使用的策略和原始文字片段，方便复盘与修正。

这不是一套让人照念的标准答案，而是一个低成本试错的练习场。它更关心你能否听懂客户、选择合适的动作，并让每一次沟通自然地往前走。

## 快速体验

```bash
npm install
npm run dev
```

打开 `http://localhost:5173`，点击“快速开始一通”，即可使用内置场景体验完整流程。未配置模型密钥时，项目会使用演示模式运行。

如需接入真实模型，请在仓库根目录创建 `.env.local`：

```env
MIMO_API_KEY=你的密钥
MIMO_BASE_URL=https://token-plan-cn.xiaomimimo.com/v1
MIMO_MODEL=mimo-v2.5
```

`MIMO_BASE_URL` 和 `MIMO_MODEL` 可以省略，系统会使用默认值。密钥只在本地服务端读取，不会发送到浏览器。

## 导入优秀录音

录音转写放在后台运行，不会让前端对练停下来等待：

```bash
npm run audio:ingest -- "D:\path\call.m4a"
```

支持 `mp3`、`m4a`、`wav`、`webm` 和 `ogg`，单段不超过 25MB。系统会先转写录音，再整理经理与客户的发言轮次，生成一份待校对稿。

待校对稿默认保存在 Git 忽略的 `data/audio-intake/`。请先人工核对并完成脱敏，再交给素材库分析；录音和转写结果都不会自动发布。

## 开发与验证

| 命令 | 用途 |
| --- | --- |
| `npm run dev` | 启动网页与本地服务 |
| `npm test` | 运行测试 |
| `npm run typecheck` | 检查类型 |
| `npm run build` | 构建可部署版本 |
| `npm start` | 构建并启动单进程版本 |

项目仍在持续打磨中，当前重点是首次电话触达中的策略练习与复盘。它不用于替代合规审查、正式客户沟通或人工专业判断。
